# 効果の検討記録（NANKA DEKIRU）

参照：https://esoragototv.com/tools/nanka-dekiru/ （カタログ 156 件）

## 実施内容と範囲

- カタログ（catalog.json）とサムネイル、デモ HTML（t10・p24・s12・s16 など）を取得して確認した。
- ページ本体は動的に組み立てられるため、取得結果は骨組みだけだった。そこで catalog.json を直接読み、プロンプトの組み立て手順（〔 〕の入れ替え）を手元で再現して、下記の「入力」を作った。
- 動作確認：ヘッドレスブラウザで t10（ピント送り）と p24（タイル崩し）の**静止画の画面**を撮影して見た。連続再生での動きは**未確認**。
- 採用の判断は、サムネイル・デモの見た目・説明にもとづく。実装はしていない（制作側が行う）。

## 採用（5 件）

| 効果（ID） | 使うカット | 使い方 | 作品用に変える点 |
|---|---|---|---|
| ピント送り（t10） | 06 | 「他人事」から「自分」へ視線を移す（比較・因果の場面なので 3D 可） | デモの BokehPass は暗背景向けで、点状のにじみが出た。文字は DOM の CSS blur で代替できる。ライトな背景で試す |
| パートカラー（y42） | 04・05・07 | 彩度を落として「削られた」状態を見せ、07 で琥珀と赤だけが戻る | 人物の色分けではなく、面と文字の色に使う。残す色は 1 つずつ（赤→琥珀） |
| 線が描かれる図（s12） | 01・02・03・05・08 | 温度計の線、赤点と青点を結ぶ線、測り線、起点の線 | 手順図ではなく「温度差の距離」の線として使う |
| キネティック・タイポ（s16） | 02・03・05・08・09 | 語ごとに行マスクで叩き込み、強い語を最大サイズで出す | 文字を揺らさない・散らさない。「背景を一瞬揺らす」は画面全体の押し込みを 03 の 1 回だけにする |
| タイル崩し（p24） | 04 | 面（色の背景）の端が階段状に欠けて落ちる | 文字ではなく面にだけ使う。球は使わず、03 の球の続きで壁側が欠ける |

### 入力（一般化した依頼文：5 件）

内部の作品名・個人情報を含まない形で、`〔 〕` を差し替えて作成した。

- 作品：熱量の温度差で心がすり減る感覚から、自分で動かせることへ関心を戻す流れを伝える約 1 分 25 秒の体験談映像。短い日本語のタイポグラフィを主役に、小さな炎の実写を 1 場面だけ組み合わせる。
- ねらい：左右の色面（赤と青）の温度差を温度計の線の往復で見せる。前半は熱を持つ側の面が削られ、後半は試したいことが灯って色が戻る。最後に焦点が他人から自分へ移る。読む文字の形は揺らさない。
- 各効果の「作り方」は、カタログの記述に〔画の並び〕〔素材〕〔残す色〕などを企画の語で入れて作成。

## 不採用と理由

| 効果（ID） | 理由 |
|---|---|
| サーモグラフィ風（g14） | 「温度」のイメージには近いが、暗い疑似カラー表現でライトな画面と合わない。赤と青の意味が二重になる |
| 波のゆがみ（g07） | 読ませる文字が揺れる。文字の形は保つ方針に反する |
| ブルーム・ネオン（t06） | 暗背景向けの発光。ライトな絵コンテと合わない |
| カウンター（s14） | 画面に数字を出さない（根拠の数値が原稿にない） |
| 文字の中に動画（s18） | 実写を文字の内側に入れると、読む文字の形が崩れる。実写は 07 の窓 1 つに限る |
| 動きで色（y24） | 色の意味（赤＝自分の熱量）を動きで変えると記号の意味が増える |
| 奥行きの霧とピント（y97） | 06 のピント送りで足りる。霧は暗いトーン向け |

## 注意（企画側の判断として制作側に渡すこと）

- 全体の動きは「カメラ・面・線・マスク」で作り、文字そのものを 1 字ずつ散らさない。
- 3D は 06 のみ。他は DOM/CSS・GSAP・SVG・Matter.js（制作側の裁量で簡略化してよい）。
- 実際の速さでの見え方（過剰な動き・読めなさ）は**未確認**。最終判断はユーザー。
