# BGM 来歴 — メンテナンスされない（できない）モノは、いずれ負債になる

- ファイル: `public/bgm.wav`（44.1kHz/16bit ステレオ、BGM単体）／完成ミックス `public/mix.wav`・`public/mix.m4a`（AAC 256kbps）
- 長さ: BGM 155.48 秒（映像 154.28 秒＝4628フレームを全尺で覆う。末尾1.5秒はフェード）。ミックスは映像と同じ 154.28 秒
- 制作: 本企画専用に **ローカルで新規作曲・合成**（`audio/bgm_build.py`、Python 3.13 + numpy 2.5.3 + scipy 1.18.1）。外部音源・サンプル・ループ素材・生成AI音楽は不使用。過去企画の曲・フレーズ・進行は流用していない（前作の合成スクリプトもコード流用なし）
- 費用: なし。利用条件: 自作のため第三者の権利を含まない
- 構成: 124BPM、E minor。区間はナレーション実尺のタイムライン（`src/lib/timeline.json`）に従い、カットの境目にライザーと衝撃音
  | カット | 進行 | 内容 |
  |---|---|---|
  | 1 | Em–C–G–D | 時計の刻み（高い金属クリック）と木の打音で始まり、2小節目からキック・8分のベース |
  | 2 | Em–C–G–D | スネア＋金属の一撃（2・4拍）、16分のハット、アルペジオ |
  | 3★ | Am–Em–B7–Em | 最も密度が高い。ベースの16分の跳ね、FMベルの主題（問いのように上がって下りきらない）。「現状維持」「劣化への」に衝撃音 |
  | 4 | Em–Cmaj7–Am–B7 | 少し暗い和声で内部の腐食へ |
  | 5 | G–D–Em–C | 明るい進行と主題（挑戦の肯定） |
  | 6 | Am–Em–C–D | ハーフタイム（キック・スネアの間隔を広げる）＝中盤の展開 |
  | 7 | C–D–Bm–Em | 推進が戻る |
  | 8 | Am–B7–Em–C | 「事業者が倒れれば」から太鼓とベースが抜けるブレイク（持続低音とパッドだけ） |
  | 9 | G–D/F#–Em–C | 全パートで戻る、主題 |
  | 10 | C–G–D–Em | 終わりの主題、最後の約3秒は Em9 の和音と散らしたベルの余韻 |
- 声の帯域: 2.6kHz 付近を静的に少し下げ、ナレーションの包絡で BGM を -7.5dB ダッキング（`audio/mix_build.py`）
- 技術確認（`audio/mix-report.json`）: ミックス 154.28 秒、ピーク -0.85 dBFS、クリップ 0、2秒ごとの RMS はおおむね -16〜-23 dBFS（末尾6秒は余韻で -26〜-30）、無音ブロックなし。発話中の声 RMS 約 -17.4 dB に対し BGM 約 -28.5 dB（約11dB差）
- **試聴: 未確認。** モデルは音声を聴取できないため、音色・ノリ・映像との主観的な相性は確認していない。数値は試聴の代わりではない
