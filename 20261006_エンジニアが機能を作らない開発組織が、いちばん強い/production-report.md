## 確認した範囲（実際に視覚・計測確認したもの）

- 書き出し: `main.mp4` は `nb_frames=3450`（=115秒×30fps、取り落としなし）、`duration=115.008`、1280×720、30/1 fps。`prototype.mp4` は 901フレーム・30.037秒。ffprobe で確認。
- 音声: 最終 `main.mp4` の積分ラウドネス -22.2 LUFS（`ffmpeg ebur128`）。準備済み `bgm-115s.wav`（-22.2 LUFS）がそのまま乗っている。効果音・生成音声は入れていない。
- 代表フレームの視覚確認（still レンダ＋本編 mp4 からの抽出の両方）:
  - 問い: 二つの声のブロックが左右から入り、中央で接触・震えの収束。引用文が読める。
  - 原因1: 天秤で「軽いもの（自分用・仲間内）」と「重いもの（個人情報・止まると困る）」を対比し、最後に水平へ戻して「どちらにも一理ある」を示す。
  - 原因2: 要望→（翻訳＝エンジニア）→機能 の経路。トークンが移動し、文字は静止。
  - 転換: 意見の文字を出さず、共通色（スレート）の二つの形が横並びから上下へ「向きを変えて積む」。着地後に「機能／実務家」「土台／エンジニア」を新しく表示。意見の色・文字は役割へ引き継いでいない。
  - 動画A（0:46–0:51）: 本文を左、動画窓を右に置き、紙を指でたどる手元を控えめに表示。変形の前に閉じる。本編 mp4 からの抽出でも実写が表示されることを確認。
  - 方法1: 二層を保持したまま、視野（中長期・成長）の枠がゆっくり広がる。
  - 方法2: 下層に支え（要件→PM・アーキ→QA→土台）が一つずつ灯る。動画B（1:26–1:31）を上層の窓に合成（下記）。
  - 結論: 関与の光を機能側から環境・品質側へ徐々に移す。機能側の光も残す。最後は静止、エンドカード・元記事表示なし。
- レイアウト: 見出し800・本文400（可変フォントの wght 軸）。本文はほぼ1行に収まるサイズ（46px基準）で左右セーフエリア内。読む間は本文を静止。
- 転換の着地形＝後半の二層の定位置を同一の幾何定数（`src/theme.ts` の `LAYER`）で共有し、転換の最終フレームと方法1の先頭が一致することを確認（継ぎ目が飛ばない）。

## 動画B（端末画面）の合成方法

`src/components/BTablet.tsx`。実素材1280×720の座標で三層に重ねた。
1. 実素材（机・紙・手・灰色画面）。
2. 端末画面の四隅（代表フレームから採寸：左上628,178／右上1055,192／右下1040,455／左下614,442）に `clip-path` で作画UI（`TabletScreen.tsx` の架空の作業記録画面）を敷く。
3. 同じ実素材をもう一度、灰色を `@remotion/effects` の `colorKey`（keyColor #8b8c8e）で抜いて同じ四隅にクリップして重ね、画面に掛かる指を前面へ戻す。

端末UIを前面に貼って手を消すのではなく、灰色だけを抜いて手を残す方式。still と本編 mp4 の両方で、UIが画面に乗り、指が前面に残ることを確認した。窓は小さい（320×180）ため、キーイング境界の微細な粗は目立ちにくい。UIの文言（作業記録／記録を確認する 等）は原稿の引用ではない架空の作画。

## 設計上の解釈・代替（記録）

- 「90度回転して上下に積む」: 文字を載せたまま要素をCSSで90度回すと文字も横倒しになるため、原稿の指示どおり先に意見の文字を消し、無文字の共通色の形を縦長→横長へ「向きを変える（＝長辺が縦から横へ倒れる）」動きと上下への移動で表現した。文字が読める間は回転させない。リテラルな見た目のスピンではなく、向きの転換として実装している。
- 二つの声と役割の非同一視: 問いのブロックは二色（テラコッタ／ティール）だが、転換ではこの色・文字を使わず共通のスレート一色で積む。「AI任せ派＝実務家」等の一対一対応は作っていない。
- `video/public/` の素材は `../assets` からのコピー。バンドラがプロジェクトルート外へ出るシンボリックリンクを配信せず（フォントが404になった）、やむを得ずコピーにした。元本は `assets/` 側のまま変更・削除していない。コピーは `.gitignore` で Git 管理外にしており、二重コミットは避けている。
- 動画の採用区間は plan 準拠（A 0:46–0:51、B 1:26–1:31）。原本0.5–5.5秒の無音5秒版をそのまま使用。原本は変更していない。

## 再実行コマンド

作業ディレクトリ: `video/`

```bash
cd video
npm install                 # 依存（Remotion 4.0.533 で固定）
npx remotion studio         # プレビュー編集
# 試作（0:41–1:11）
npx remotion render src/index.ts Main output/prototype.mp4 --frames=1230-2130
# 全編
npx remotion render src/index.ts Main output/main.mp4
```

`remotion.config.ts` で `Config.setChromiumOpenGlRenderer("angle")` を設定済み（`colorKey` のWebGLに必要）。
`video/public/` が空の場合は `assets/` の `cut-A/B-…-5s.mp4`・`bgm-115s.wav`・`fonts/NotoSansJP-wght.ttf` を `cut-A.mp4`/`cut-B.mp4`/`bgm.wav`/`NotoSansJP.ttf` としてコピーする。

## プロジェクト構成

- `src/font.ts` ローカル Noto Sans JP の読み込み
- `src/components/` ui（背景・読む一文・イージング）、TwoLayer（二層）、TabletScreen（端末UI）、BTablet（B合成）
- `src/scenes/` Question / Cause1 / Cause2 / Pivot / Method1 / Method2 / Conclusion

すべての動きは `useCurrentFrame()` と `interpolate()` で決定。CSSアニメーション／transition は使っていない。
