# 素材制作・収集のフィードバック（依頼元共有用）

2026-10-06。今回の素材選定と編集で確認した事実をもとに、次回の企画・素材依頼へ反映する。

## 結論

良い企画と素材が先に揃うと制作は進めやすい。ただし、先に大量生成するより、使用場面・画面構成・採用条件を決め、少数の素材を実際に文字や図形と組み合わせて確認してから追加する方針にしたい。

主表現は、画面全体が大きく動くキネティックタイポグラフィ×モーショングラフィックス。実写素材にも激しい動作を求める必要はない。素材の自然な動作と画面全体の勢いを組み合わせる。固定カメラの素材でも、編集で移動・拡大・構図の切替を付けられる余地を企画する。

## 次回はこの順で進めたい

1. **素材依頼前に企画を具体化する。** 各素材が支える主張、対象場面、使用尺、画面全体の動き、文字との配置、必要な合成を決める。既存素材や作画で足りる場面も確認する。
2. **配置見本と採用条件を渡す。** 共通参照に加え、最終画面の見本と切り取り範囲を用意。生成サービスへの参照と編集者向けの配置見本は分ける。
3. **最小限の候補から確認する。** 必要なカットをまず各1案程度で検証する。初期生成・テストにも、既存の費用レビューと承認方針を適用する。一度に多数の別案を作らない。
4. **実際の画面に組み込む。** 文字・図形・音楽と組み合わせ、最終サイズで動き、切り取り、可読性、合成負荷を見る。生成画像の見栄えだけで動画の採用を決めない。
5. **不足分だけ追加する。** 何が不足し、指示のどこを変えるかを具体化。破綻を理由に再生成する場合と、画面構成の変更で別素材が必要な場合を分ける。追加費用を確認し、承認範囲内で実行する。

## 素材依頼票に入れる情報

| 項目 | 依頼時に決める内容 |
|---|---|
| 用途 | カット名、伝える主張、素材が担う役割 |
| 画面構成 | 最終縦横比、表示位置・大きさ、文字の位置、切り取り範囲、画面全体の動き |
| 動作 | 開始状態→主動作→終了状態、手や人物の数・左右、使用尺と編集の余裕 |
| 参照 | 共通の写真・スタイル参照、必要なら開始／終了の見本、編集用の配置見本 |
| 合成 | UIなどを後から載せるか、隠れる物や手の前後関係、先に試す処理 |
| 採用条件 | 動作・形・連続性・画角・実表示サイズでの品質。即不採用の条件も明記 |
| 生成範囲 | サービス・モデル、生成回数、想定費用、追加生成の判断条件と承認範囲 |
| 納品 | 加工前の原本、使用推奨区間、実際の仕様、参照とプロンプト、生成履歴・費用・利用条件の確認状況 |

## 引き渡しと保存

採用素材は用途が分かる名前にする（例：`cut-A-paper-tracing.mp4`）。原本と編集版、共通参照と完成素材を分ける。採用区間・条件・不採用理由を短い台帳に残す。使わない重い動画をリポジトリへためず、整理時も理由と元情報を残す。

今回の各素材の正確な生成サービス・モデル、実際の費用・利用条件は未確認の部分がある。依頼元へ納品情報として提供してほしい。記録から削除8本分の生成費用を算定することはできない。
