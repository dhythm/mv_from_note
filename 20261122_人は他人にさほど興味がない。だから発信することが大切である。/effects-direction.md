## 入力する一般化した説明

- 作品・場面：明るい紙色のキネティックタイポグラフィ。点の列が右から左へ流れ、大半は素通りし、二つが減速し、一つが中央へ寄って短い吹き出しになる。カメラはその一つへ、3秒かけてゆっくり寄る。
- ねらい：文字の形は崩さない。動かすのは点の列、線、吹き出し、語の塊、図のカメラ。全編を同じ横スクロールにしない。

ページが生成する章表示、固定手順、追加の承認待ちは採用しない。

## JIZURA の語彙

[JIZURA](https://github.com/852wa/JIZURA) は、歌詞から文字PVを組むブラウザアプリ。利用は必須ではない。ここではアプリを動かしていない。参照したのは、このリポジトリのスキルが v0.13.0 の README からまとめた部品名だけである。非公開原稿は入れていない。NANKA DEKIRU の確認の代わりにはしていない。

- 流れる帯：字の帯としては採らない。01で、点の列が水平に流れるレイアウトを考えるときの言葉としてだけ使った。
- ゆっくり寄る：02のドリーイン（3秒、ゆっくり）の言い方の参考。カメラは点の層だけに掛ける。
- ワイプ：語の塊が行のマスクから入る。1字ずつではない。
- ドリフト：読む間、語の塊や線をゆっくり流す。字形の揺れにはしない。
- プッシュ：07の結びで、語と点を一つの塊として寄せてから、ライムの全面へ横に振る。

採らない部品は、ジッター、グリッチ、爆散、拍ごとの脈動、飾りの数字。文字の形を崩すものと、意味のない飾りである。

## 制作への引き渡し

plan.html には、点が流れる、二つが減速して一つが前へ出る、吹き出しが一塊で出る、余白が広がる、輪郭の丸が線に乗る、弧が寄る、斜線が語の手前で切れる、結びで点が再び出る、という各カットの狙いを記載した。見本のコード・画像・音は転載しない。仕組みはフレーム時刻から決まる実装へ翻訳する。最初の試作は 01→02 で、点の速度差と、寄っているあいだ吹き出しの文字が読めることを等速で確認する。
