# layout-notes — ガント変形と文字の安全域

想定キャンバス: 1280×720 / 30fps（テスト資産。1920×1080は作らない）

## 安全域
- テキスト: 上 56px / 左右 64px / 下 48px
- ガント変形ゾーン: 概ね x=160–1120, y=180–620
- 見出し級のキネティック文字は上帯（y=56–170）を優先。変形中はガント上に重ねてよいが、テロップ帯・ロゴは使わない

## 4状態の役割
1. `gantt-01-filled.svg` — 問い。日付が埋まるが安定しない
2. `gantt-02-shift-week.svg` — 誤案。全バー+1週。半透明のゴースト元位置つき
3. `gantt-03-split.svg` — 実施中バーが途中で割れる（塗り分け≈7:3）。※演出割合
4. `gantt-04-insert.svg` — 正しい着地。区切り済み＋追加の後ろに残り行

SVGネイティブ幅は960。配置時に約1.05–1.15倍で中央寄せ。

## 動きの原則
- バーと日付数字がオブジェクト。拍と拍のあいだはこれらの移動・伸縮・割れでエネルギーを運ぶ
- 文切り替えをフェードのみにしない
- 変形（02→03→04）は一度だけ連続。着地後はガントを大きく動かさない
- 「7割／3割」は厳密計測ではない。オンエアで計測を示唆するラベルを足さない
