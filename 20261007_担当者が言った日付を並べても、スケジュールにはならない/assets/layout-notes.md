# layout-notes — 文字・ガント・期限・判断の配置

2026-10-07改訂。1280×720／30fpsの試作想定。場面と時刻は `../plan.md` を正とする。

## 安全域と注視対象

- 文字の基準安全域: 上56px、左右64px、下48px。主張の主要語は読ませる区間で安全域に保つ。
- ガント比較の基準ゾーン: x=160〜1120、y=180〜620。全面化・接近・回転時は一部が画面外へ出てもよいが、比較の着地で必要な時間軸・行名・期限線を見せる。
- 上帯固定は撤回。中央・全面・左右比較・奥行き配置を切り替え、文字自体が図形と連動して構図を変える。
- 一度に読ませる文と、注目させる変形を競合させない。文字→変形→比較の順序をつくり、構図と周辺要素はその間も動かす。

## 既存4状態の位置づけ

1. `gantt-01-filled.svg`: 日付の集合の参考。冒頭では追加タスクの割り込みまで見せる。
2. `gantt-02-shift-week.svg`: 一律右ずらし案の参考。元位置と影響対象を比較可能にする。
3. `gantt-03-split.svg`: 完了部分と残作業の分離の参考。
4. `gantt-04-insert.svg`: 使った時間を読み解ける記録の参考。納期解決・顧客承認を意味しない。

既存SVGは完成レイアウトではない。日付座標・残作業の幅・注記を採用前に再設計する。特に追加作業が完了部分より前の時間に見える配置を避け、完了→追加→残作業の関係を明確にする。進捗7割と期間幅7割の一致は仮定しない。

## 動きと接続

- 冒頭: 日付の奥行き移動→ガントへ収束→追加タスクの横衝突→右ずらし。微振動だけでつながない。
- 影響・短縮: 依存線に沿う移動→余白の生成→4週の内部区画→二例への展開→実施中バーへ戻る。
- 分割: 完了部分の元時間位置を示し、残作業を分離して追加後へ。画面も追従・回転し、着地で全体比較へ引く。
- 分割後: ガントの縦展開→各行への接近→全体への引き→期限線の侵入。大きな動きを止める制約は置かない。
- 判断: 期限線を支点に案とリスクを左右へ展開。比較の焦点を大きく移動し、関係者に判断を求めるところまで描く。承認済みの記号は出さない。
- 結論: 冒頭の集合を奥へ、リスクと判断を伴う計画を手前へ。主要語とバーの構図再編を続け、音楽の終止へ収束する。

画面の移動・拡縮・回転で、実際の日付が変更されたように見えないよう、比較時には軸・元位置を示す。大きな変形の回数は限定しない。

## 色と意味

背景 `#f7f6f3`／インク `#3a3a3a`／通常バー `#4a5a6a` `#5a6a7a`／追加・警告 `#8a5a4a` `#c45c3a`／完了部分 `#3a5a4a`。

色だけに意味を依存せず、行名・形・位置でも区別する。完了部分の緑を、計画全体の承認・納期保証に転用しない。7割は説明用の割合として制作メモに残し、実測の目盛りを追加しない。
