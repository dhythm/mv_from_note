## 編集への引き渡し

- SVGは配置見本兼編集元。8枚を画像として順に切り替えるだけで本編にしない。各id要素を動かし、plan.mdの場面間の接続を実装する。
- 見本のfooterと、制作指示・計測注記を含むsubheadlineは編集者向け。完成画面に一律に焼き込まない。本編の文言はreferences第3節を正とし、必要な留保はその文言で読ませる。
- 01は追加前の静止状態もaddedグループを外して作れる。02の元位置、05の浮いた残作業、06の期限線は個別に動かせる。
- 04の二例は工程の事実ではなく説明用。中身を保つ短縮と削る短縮を別々に見せる。07は選択肢を示す構造であり、実現効果や承認結果を捏造しない。
- 配置は最終表示サイズで目視したが、動画での勢い・追跡・可読性は未検証。previewsのPNGは確認用で、本編に焼き込む素材ではない。
- Noto Sans JP可変フォントをassets/fontsへライセンス文とともに準備。本編でローカル読み込みする。PNG見本は環境の日本語フォントによる描画であり、同梱フォントの本編での描画検証は別途必要。

## BGM候補

bgm-205s-draft.mp3は既存約190秒の音源を編集した候補。205秒、44100Hz、モノラル128kbps。0〜174秒に143〜175秒を1秒クロスフェードでつなぎ、最後3秒をフェードアウト。prepare_audio.pyで再生成できる。再エンコードによって原本の音質が向上するわけではない。

デコードと長さ、最大ピーク-11.3dBFSを確認。試聴は未実施で、楽節の接続、拍、終止の自然さは未確認。映像198秒なら途中で切るだけにせず、確定尺に合わせて終止を再編集する。必要なら接続位置も試聴後に変更する。音源の自作合成という来歴は旧referencesの記録を継承しており、今回独立に制作履歴を検証したものではない。

## 現在の到達点

試作に進むための基本素材は準備済み。残るのは同梱フォントの実表示確認、図形を動かした試作、音源の試聴・拍合わせ・確定尺への編集、実際の文字と音楽を合わせた採否判断。完成素材・完成映像の合格ではない。詳細な仕様と確認状況はmanifest.json。
