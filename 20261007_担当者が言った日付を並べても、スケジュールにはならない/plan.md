# 担当者が言った日付を並べても、スケジュールにはならない

## 最初に分けること

維持するもの
- 表現形式は、顔出し・画面収録・ナレーション録音なしのキネティックタイポグラフィ／モーショングラフィックス。文字と図形（ガントのバー）が主役。画像・動画は補助。
- 記事の主張は「担当者の希望日を並べたガントはスタート地点にすぎない。PM の仕事は、遅れたときの影響を読み、成功する形に組み替えること」。
- 目玉の動き（一律に1週間右へずらす案が通りにくく、7割進んだバーが割れ、残りの3割が追加タスクの後ろに差し込まれる）と、その意味（お客さんが納得する組み替え／あとで読み解ける記録）。
- 理由を落とさない。バッファは「遅れたら何が起きるか」を聞いてから。早まる計画は中身を見る。「右にずらします」だけでは太刀打ちできない。細かく切る理由は、あとで工数を読み解くため。
- 結論の前置きはないが、成功したら PM のおかげでもある、という結びは残す。

変えてよいもの
- 上映順。記事は相談の場面 → バッファ → 早まる計画 → 右ずらしの問題 → 細かく切る → 結び。映像は「日付が埋まっている」状態から入り、右ずらしの失敗と正しい組み替えを中心に据える。バッファと早まる計画は、組み替えの前後で「日付の中身を読む」例として置く。
- 画面の文言、書体、配色、間。最終判断は作業者。
- 尺。目安は約3分（画面文字約1000字）。文字数と動きの観察時間で最終調整する。3分固定にしない。

提案側の仮説（原稿にはない、こちらの発明）
- ガントのバーと日付の数字そのものを画面上のオブジェクトにし、文字の主張と同時に動かす。原稿は図を指定していない。
- 「7割／3割」は原稿の「7割、8割」から取った演出上の割合。厳密な進捗計測ではない。

## 動き

### 課題は1つ（意味を担う変形）

全部のバーが一律に1週間右へずれたあと、7割進んだバーだけが途中で割れ、残りの3割が新しい行として追加タスクの後ろに差し込まれる。

- 意味: 「右にずらします」は実施中の仕事まで押し流すので通らない。進んだ分を残し、残作業を追加タスクの後ろへ差し替えると、外枠では延びていても中身が読み解ける。
- 変形は一度だけ、方法の中心拍で起こす。着地後は正しいガントが残り、以後はバーを大きく動かさない。
- 「割れ」と「差し込み」は同じ変形の連続として扱い、二つ目の比喩にしない。

### 全編の勢い（20261006 の既定）

ユーザー補足（2026-10-07）: 情報を伝えることも大切だが、映像で魅せることも目的。映像制作の練習も兼ねる。主張を落とさず、画面全体の勢いで魅せる方向を優先する。情報の正確さのために動きを弱めない。

大きな変形をこの一箇所だけに限定して、前後を文章のフェードと静止にしない。読ませる区間も、語の拡大縮小、日付数字の移動、バーの伸縮、構図の組み替え、視線の誘導で勢いを引き継ぐ。入口と出口だけ動かす実装にしない。代表静止画だけでは動きの合格を判定しない。冒頭・中盤（変形）・後半の試作で勢いを確認する。

## 合格の条件

note を読んでいない人が見終わって、次を自分の言葉で言えること。
- 担当者の日付を並べただけでは、なぜスケジュールではないのか。
- バッファを置く前に何を聞くのか。
- 早く終わる見積もりを、なぜそのまま喜ばないのか。
- 一律に右へずらす案の何がおかしく、バーを割って差し込むと何がわかるのか。
- 結論が「並べた日付はスタート地点で、組み替えて初めてスケジュールになる」であること。

不合格: 「ガントを細かくしろ」「バッファを置け」「PM は大事」だけが残る。理由（遅れたときの影響、中身の「できる」、実施中までずらす違和感、あとで読み解ける記録）が落ちる。文字を外して分かるかどうかは基準にしない。

## 制作の進め方

1. 素材依頼の前に、ガント図形の配置見本（変形前／一律右ずらし／割れ／差し込み後）と、文字との安全域を決める。
2. 全編の前に、(a) 問い〜転換の種、(b) 変形区間、(c) 結論寄り、の短い区間を等速で書き出して勢いを見る。代表静止画だけでは合格にしない。
3. 書き出しの完了と、作品として通ったことは分けて報告する。
4. 書き出し中に素材を更新しない。

## 素材

- 必須はガントのバーと日付軸（コードで作る図形）。静止画の枚数を進捗にしない。
- アイコンを使うなら人物シルエット程度。軽い WebP か SVG。
- 実写・生成動画は使わない前提。ガントの変形は作画で足りる。もし提案するなら、対象・範囲・クレジットを示し、明示承認の前にテストしない。
- 素材は先に使い方（場面・尺・文字との配置・画面全体の動き・切り取り・合成）を決めてから、少数で確認する。

## これがあればもっと良くなる

- ライセンスがはっきりした、拍の明確な控えめな器楽曲1本（変形の右ずらしと割れに合わせられるもの）。
- 日本語の太い見出しと細い本文の組（商用可）。日付の数字と主張の文の階層が書体で出せる。
