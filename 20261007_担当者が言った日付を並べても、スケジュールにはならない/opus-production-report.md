## 1. 技術方針

- Remotion 4.0.533（React 19）。全アニメーションは `useCurrentFrame`+`interpolate`＋フレームから直接評価する減衰振動（P23のばね）。GSAP/実時間物理は不使用。任意フレームで同一状態＝決定論的で再現可能。
- 各シーンはグローバルフレームで描画制御（Sequenceのローカルオフセット不使用）。音楽同期を全編で一貫させるため。
- 依存環境は隣接企画の `node_modules` を共有（symlink）。追加インストールなし。費用0。
- 仕様: 1280×720 / 30fps / 198.0秒（3:18）= 5940フレーム。
- フォント: 同梱 Noto Sans JP 可変（`@remotion/fonts` でローカル読み込み、`delayRender` で読込完了を待つ）。

## 4. BGM（最新 feedback 準拠）

- 現行 `assets/bgm.mp3`・`assets/v2/bgm-205s-draft.mp3`・`video/public/bgm.mp3` は不採用。延長・音量調整での再採用もしていない。波形・フレーズの流用なし。
- **ローカルで新規に合成した器楽トラック**（Python/numpy、`audio/bgm_build.py`）。150BPMの推進力あるエレクトロ。キック/スネア/ハット/ベース/アルペジオ/パッドを場面に合わせ密度・強弱変化（intro→場面5の見せ場→場面6–7のピーク→場面8の収束）。効果音なし。
- 150BPMを30fpsグリッド（12frame/拍）に一致させ、Y20/Y21をフレーム決定論的に同期。映像の速度をBGMに合わせて遅くしていない（むしろBGMを映像の躍動感に合わせて設計）。
- 音量は本文の理解を妨げない範囲（Audio volume 0.72）。来歴・使用条件は `MUSIC-SOURCE.md`。
- **未確認（重要）**: モデルは音声を聴取できないため、音色・ノリ・映像との主観的相性の**試聴は未確認**。合格を断定しない。ユーザーによる冒頭・分割・後半の試聴での採否確認が必要。拍グリッドと映像の一致・長さ・ピーク(-1.5dBFS)・無音でないことは数値/構造で確認済み。
