# マネタイズを捨てたら個人開発が楽しくなった

> 状態: **企画 v1**。原稿（private-note）を読み、論拠をカット表へ反映済み。画面の文言は v1 案（調整可）。絵コンテ画像は未作成（「未達」参照）。

## 最初に分けること
### 変えないもの
- 主張: マネタイズ／ユーザー数を前提に企画すると、開発の心理的ハードルが一気に上がる。自分が使う小さな道具を、無料枠でその日のうちに動かすと、作る楽しさが戻る。
- 論拠の順序（結論だけにしない）: 収益・集客が前提だとセキュリティや運用の責任が重くなる → 自分が最初のユーザーなら自分の不便が消えるだけで元が取れる → 無料枠なら固定費も独自ドメインも要らない → 思いついた日に動く形へ → 例：URLを共有するだけで使える「調整さん感覚」の道具 → 使わなくなったら静かに閉じればいい → 壮大な成果より小さな道具を育てるほうが長く楽しく続く。
- 実践の動き: 中央の大看板「マネタイズ／ユーザー数」が**スマッシュカット（0.3秒・瞬時・看板ごと）**で消え、**ズームイン（3秒・ゆっくり）**で小さな道具アイコン「自分が使う」へ寄る。
- 形式: キネティックタイポグラフィ×モーショングラフィックス。後半も画面全体が動き続ける。
- 最後にエンドロゴ（`okady-work-logo.svg`、背景 `#d2ff1a`、完成状態を1〜1.5秒保持）。
- 出典クレジット・章タイトル・字幕帯・追加ロゴは入れない。
- 「調整さん」は画面の言葉（口頭の比喩）のみ。ロゴ・UIは出さない。他者の著作物・実在サービスのUIは使わない。
### 変えてよいもの
- 各カットの秒数（可読性・BGMに合わせて±）、文言の言い回し、図形の種類、配色（ロゴ色以外）。
- 実写/生成素材の有無（なしで成立させる）。
### 仮説
- 看板を「消す」一撃が主張の転換点として最も効く。約11秒に置けば続きを見る理由になる。
- 「URLだけ→候補日グリッドが埋まる」は、軽さ（作ってすぐ使える）を言葉より速く伝える。
- 「その日のうちに」「無料枠」「固定費0」などの数値・期間は例示。サービス名（Vercel / Neon 等）や具体的な上限数は画面に出さない。

## 動きの課題は1つ
「重い前提が消えて、軽くなる」感覚を、文字を読ませながら画面全体の運動で出すこと。前半は重く積み上がる・押し付ける動き、転換後は軽く回る・弾む動き。どちらも静止させない。

## 表現方針
- **three.js を採用**（AGENTS.md の推奨どおり）。Remotion 上でフレーム時刻から位置・回転・スケールを決める再現可能な実装にする（`requestAnimationFrame` 直結は不可）。
- 文字のフェードだけの登場、スライド資料風の順次表示は禁止。読む区間も拡大縮小・回転・カメラ移動を継続。後半（カット6〜8）も動きの密度を落とさない。
- 色: 前半は暗い灰＋警告的な赤、転換後は明るい白地＋ライム（エンドロゴへ自然につなぐ）。
- 書体: Noto Sans JP（太）を主、補助に細字。

## 合格条件
- 原稿を知らない人が「マネタイズ前提→責任と固定費でハードル上昇→自分用・無料枠・即日→URLだけの軽い道具→閉じてもいい→楽しさが戻る」の筋を追える。結論だけでなく理由が画面にある。
- 0.3秒のスマッシュカットが看板ごと瞬時に消え、続く3秒のズームインがゆっくり読める。
- 全カットで画面全体が動いている。フェードのみ・スライド風・後半の静止がない（冒頭・中盤・後半を動画で確認）。
- 素材なしで成立する（カット5–6は代替モーショングラフィックスで完結）。
- 「調整さん」のロゴ・UI、他者の著作物が出ない。出典クレジット・章タイトル・字幕帯・追加ロゴなし。
- エンドロゴのタイミング・保持・BGMの終わり方を実再生で確認済み。
- 等速再生で全文が読める。
