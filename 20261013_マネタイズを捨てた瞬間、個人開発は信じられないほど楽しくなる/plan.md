# マネタイズを捨てたら個人開発が楽しくなった

> 状態: **企画 v2・文書改訂**（2026-10-13）。PR #17 のマージ後の main `7e38eb0` を起点に、原稿を再読して改訂。AI動画・絵コンテ・音楽・実装は未制作。これは制作前の設計であり、映像品質の検証完了ではない。

## 改訂の理由と変えないもの

v1 は three.js の文字・図形がほぼ全編を担い、動画は約1秒の任意素材だった。今回の依頼に合わせ、**6〜15秒のAI生成素材と、後合成するキネティックタイポグラフィ／モーショングラフィックスを組み合わせる**。素材には「重さ」「自分用の道具の手触り」「少しずつ育つ楽しさ」を担わせ、装飾背景だけにしない。

- 主張と順序: 収益・集客を前提にすると心理的ハードルが上がる → セキュリティ・運用・固定費が重い → 自分が最初のユーザーなら不便の解消で元が取れる → 無料枠で、思いついた日に動かす → URLだけで共有できる軽い道具 → 使わなくなったら静かに閉じる → 壮大な成果より手元の小さな道具を育てる。
- 転換: **11.0秒で看板ごと瞬時に消す0.3秒のスマッシュカット、続く3秒のゆっくりしたズームイン**。生成映像にこの正確なタイミングを任せない。
- 本編45.0秒＋エンドロゴ5.5秒＝**50.5秒、30fps・1515f**。9カットの境界も維持。
- トーン: 前半は重く圧迫、後半は軽く弾む。MVのように画面全体が大きく動く。無言の人物劇にせず、理由と留保は文字で伝える。
- 出典クレジット・章タイトル・字幕帯・追加ロゴは入れない。「調整さん」は比喩の言葉だけ。実在サービスのUI・ロゴ・映画ポスターなどは使わない。
- 収益化一般を否定したり、自分用ならセキュリティ責任が消えると断定したりしない。「無料枠」は原稿の実践方針であり、どんなアプリでも永久無料という保証ではない。

## 合成・動きの設計

Remotionで動画の採用区間と文字／図形のタイムラインを合わせる。three.js は看板・道具アイコン・文字／動画面を動かす手段として継続採用するが、全場面を3Dだけで生成する前提を改める。動画は平面として扱い、映像内の物体を無理に3Dへ追跡しない。位置・回転・スケール・マスクはフレームから再現可能にする。

- 日本語・数値・URL・候補日・○・ロゴは**生成映像に焼かず後段で制御**。素材上の板へ細かい文字を貼り込まず、余白の独立した文字や図形で意味を結ぶ。実在URLは表示しない。カードは「URL」の抽象表記。
- 1280×720・16:9、外周5%を文字の安全域の基準にする。表の x/y は完成画面に対する百分率。読む文は原則2行以内で順に差し替え、同時に長文を並べない。Noto Sans JP 太字、説明36〜44px・主張56〜88pxを試作開始値とし、実サイズで調整する。
- 動画と文字の面をまとめて傾ける／寄る／横へ送る大きな運動と、意味のある語の拡縮・配置の組替えを重ねる。読む間も動くが、裏返す・画外へ追い出す・全面をぼかす区間に新しい文を読ませない。
- 生成素材のカメラは控えめにして、編集の大きな移動と二重に暴れないようにする。縦横比を保ち、数値は採用時に実ファイルから記録。生成のfpsを30と決めつけず、編集版で30fpsへ正規化し、採用区間は実フレームに丸める。生成音声は外す。

## 音と制作方法の比較

BGMは前半の重い反復→11秒の0.3秒無音→軽く跳ねる後半→ロゴの余韻という構成の新規コード合成曲を検討する。速度感のあるリズムとアクセントを持たせ、50.5秒を覆う。BPM・拍位置は未決定。カット境界とスマッシュ／ズームの固定尺を優先し、語の動きやAの接触を採用曲のアクセントに合わせる。ナレーションは今回追加しない。

- AIの価値: 物体の接触・柔らかな陰影・微細な材質・開くときの手触りを、文字の抽象性に組み合わせられる。Aの圧迫とB/Cの軽さが論旨の対比になる。
- three.jsのみ: 正確な意味・タイミング・再現性に強いので看板の消失、URL、グリッド、閉じるアイコン、ロゴに使う。素材不採用時は板／タイルも同様の動作で代替可能。ただし今回の第一案はAIとの組合せ。
- 撮影／Blender: 同じ素材の物理感を作れるが、撮影準備や材質・光・アニメーション調整が必要。今回はその制作も行わず、AI素材の採用判断で負荷・品質を比較する。
