# 制作指示書：マネタイズを捨てたら個人開発が楽しくなった

## 作るもの

1280×720・16:9・30fps、全50.5秒の動画を制作する。本編45秒＋エンドロゴ5.5秒。キネティックタイポグラフィとモーショングラフィックスを主表現にし、採用済みマスコット動画3本を背景分離して組み込む。

伝える流れは「収益・集客を先に考える重さ → 自分の不便を解消する価値 → 小さく動かして共有する → 使わなくなったら閉じる → 身近な道具を育てる楽しさ」。ナレーション・読み上げ字幕は付けない。画面の文言は下のカット表を使う。

## 引き渡しと役割分担

企画側は、指示書・絵コンテ・採用動画・フォント・ロゴを揃えて作業者へ渡す。BGMは下記の音楽指示に沿って作業者が使えるツールで制作する。企画側による音源の事前制作・同梱は引き渡し条件にしない。

画像・動画素材（BlenderによるPrevis動画を含む）は企画側で用意する。不足が判明した場合も、作業者へ新規制作を任せず企画側へ返す。

作業者は提供素材の合成・編集と、Three.jsやCraftingApps等によるモーショングラフィックスを制作する。BGMは[音声制作の手順](audio-production.md)に従い、Pythonによる追加課金のない制作か、利用可能な音楽生成サービスかを品質・時間・費用で判断する。今回のナレーションは追加しない。

## 画と合成

- 本編の基本色は生成り `#f6f1e7`、墨色 `#151c23`、テラコッタ `#b76145`、淡いアプリコット `#e6b889`。前半は墨色、後半は生成りを主体にする。ライム `#d2ff1a` は45秒以降のロゴ画面だけに使う。
- 看板・責任の札・道具・時計・雲・URLカード・候補日グリッド・輪を編集で作る。文字や図形を動画に焼き込まず、別の要素として動かす。
- 原本の緑背景を除き、あご下・腹部・手の緑かぶりと輪郭を補正する。接地影は編集で作る。キャラクターの全身高は280〜340pxを基準にし、顔の大写しへ拡大しない。
- 重ね順は「背景 → 後景の看板・文字 → 道具・接地影 → キャラクター → 前景の縁・札 → 主張の文字」。顔と読む文言を隠さない。
- M2の実素材は手を差し出す動き。手先の軌道に道具のつまみを合わせ、動かした瞬間に道具の反応と輪を出す。下向きのボタン押下を前提にしない。
- M3は両手を使う。道具を両手の間から右手の先に配置し、実際の手の移動に合わせてつまみを動かす。必要な接触区間だけ、道具の縁と手の前後関係をマスクで調整する。
- three.jsで文字・図形・切り抜き動画を同じ座標系へ配置する。カット表の移動・回転・拡縮を親要素へ与え、読む間も画面全体を動かす。素材を長方形の動画窓として置かない。キャラクターの平面を裏返さない。
- Remotionでは動画の再生位置、変形、マスク、揺れをフレーム時刻で決める。同じフレームを再現できる実装にする。

## 音楽

作業者が[音声制作の手順](audio-production.md)に従ってBGMを制作し、全50.5秒を覆う長さに仕上げる。前半は重い反復、11.0–11.3秒は無音、後半は軽快な打楽器と短いアクセントで道具・文字の弾みを支える。ロゴ終了で音を収める。冒頭・カット4・カット7〜8へ合わせて試聴し、映像の勢いに合わせて音量・アクセントを調整する。曲自体が合わない場合は作業者が曲を見直す。短い代表区間で映像との相性を確かめてから全尺へ仕上げる。

## 作業順と完了条件

1. 採用3本を背景分離・色補正し、編集用の30fps素材を作る。
2. カット4を組み、手先と道具の接触、輪郭、表情、文字の可読性、画面全体の動きを合わせる。その設定で残りのカットを制作する。
3. 上記の音楽指示からBGMを制作し、正規ロゴとともに組み込んで全編を調整する。
4. 冒頭・中盤・後半と場面間を等速再生で確認する。静止画の切替や登場時だけの動きに戻っていないこと、緑の縁や体の欠けがないこと、原稿を知らなくても論旨を追えることを確認する。
5. ロゴの動作・1.5秒保持・音の終わりを再生確認し、`renders/final.mp4`、再編集可能なプロジェクト一式、使用素材・BGMの出所を納品する。

表現上の注意：看板を消すのは目標設定の切替であり、セキュリティや運用責任の消滅として描かない。無料枠は永久無料の保証にしない。候補日の○は全員の合意、公開を閉じる図はデータや費用の自動消去として描かない。
