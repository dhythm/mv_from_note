# 共通キャラクター参照 v1

採用動画のデザイン参照。新規画像・動画が必要な場合は企画側で使う。

- [キャラクターシート](character-sheet-v1.png): 正面・斜め・側面・背面、ためらい／発見の表情、身構える／触れる／手直しするポーズの9枠。文字・小道具なし。
- [単体の共通参照](character-master-v1.png): 同じキャラクター一体、ニュートラルな全身。動画生成へ渡す画像は原則こちら。シート全体を開始フレームに使うと複数体になるおそれがあるため、シートは形・表情の説明用とする。
- クリーム色の丸い頭と体、濃茶の目と眉、無地のテラコッタ色ベスト、短い手足。耳・鼻・髪・装飾・ロゴなし。手はミトン状。ライム色は使わない。
- マットな粘土・樹脂のような質感。ベストの微細な質感と中央の合わせは参照に従い、ポケットやボタンを加えない。
- 背景は生成り。これはデザイン参照であり、アルファ付き切抜き素材や緑背景の完成プレートではない。M1〜M3生成時の背景指定は動画プロンプトを使う。
- 単体画像のカメラ角・画面内サイズは参考。動画では全身と手先の余白を保ち、演技に適した配置へ調整する。

## 作成と確認

組み込み画像生成ツールで2回作成（シート1回＋シートを参照した単体画像1回）。外部APIキーは使用していない。モデルの識別子・費用・クレジット消費量はツールから取得できていない。生成プロンプトは [generation-prompts.md](generation-prompts.md) に保存。

両画像を目視し、全身の欠け、9枠の役割、背面、衣装・配色・顔・手足、単体画像が一体であることを確認。採用動画の特性と合成上の注意は [素材の注意点](../review/review.md) を参照。シートのポーズは演技の参考で、動画の動作を実証したものではない。
