# 配置用絵コンテ v3

2026-10-13。各コマ1280×720。キャラクターは配置記号で、生成済み素材でも最終デザインでもありません。青矢印は移動の指示。文字の順次差替え、途中の演技・接触・構図の動きは [企画書](../../plan.md) を併読してください。ロゴは配置枠だけを示し、完成時は正規SVGを使います。
