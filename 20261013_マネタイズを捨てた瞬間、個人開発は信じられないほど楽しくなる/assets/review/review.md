# 採用素材の注意点

## 使用する原本

| 役割 | 採用ID | 原本内の区間 | 編集時の注意 |
|---|---|---|---|
| 身構える | M1-2 | 1.0–7.0秒 | 不安な表情から手を胸元へ寄せる。実際の顔の向きに看板を合わせる |
| 手を伸ばして喜ぶ | M2-1 | 0.5–6.2秒 | 下向きのボタン押下ではなく、手を差し出す演技。手先に道具・つまみを合わせる |
| 手直しと満足 | M3-2 | 0.5–5.5秒、5.5–9.5秒 | 両手の動きに合わせて道具を配置。原本内の横移動も含め、全身の切り取り範囲を確保する |

原本の実ファイルと本編内の使用位置は [制作指示書](../../plan.md) を正とする。いずれも1280×720・24fps。M1/M2は映像8秒、M3は映像10秒。音声トラックは使用しない。

## 合成で調整する点

- 緑背景は色で分離できる。あご下・腹部・手の陰に緑かぶりがあり、肌の陰の色と輪郭を補正する。
- 720p素材なので、全身高280〜340px程度を基準に使う。顔の大写しへ拡大しない。圧縮によるムラも大きく見せない。
- 手先を追い、接触する短い区間の道具・つまみ・反応を合わせる。固定した道具を置くだけでは接触が外れる。
- 原本の緑の床影は除き、接地影を編集で作る。

全12候補の時間順のコマ比較と無音再生を行い、有力4本は細かいコマ比較・仮キー処理・文字と図形を重ねた試作で確認した。これは素材適性の確認であり、本編の演出・音楽・最終接触マスクの品質保証ではない。

## 採否の記録

末尾番号なしを「1」とする。採用外の原本はユーザー指示で削除済み。生成失敗として一括扱いしない。

| ID | 判断の理由 |
|---|---|
| M1-1 | 不安の演技は使えるが終盤で手を下ろすため、持続する2を採用 |
| M1-2 | 不安への変化と胸元に手を寄せる動きが明快。採用 |
| M1-3 | 使用可能な予備。表情が早く切り替わる2を採用 |
| M1-4 | 前半に笑顔があり、不安になる時点が遅い |
| M2-1 | 手の動きから喜びへの変化が分かりやすい。採用 |
| M2-2 | 初めが不安寄りの表情。好奇心から始まる1を採用 |
| M2-3 | 序盤から微笑み、発見の前後差が控えめ |
| M2-4 | 伸ばす・戻す動きが中心で、喜びの反応は1が明快 |
| M3-1 | 片手の反復は使えるが説明の動作にも見える |
| M3-2 | 前のめりの動作と後半の満足した表情が明快。採用 |
| M3-3 | 手を持ち上げて見せる印象が強い |
| M3-4 | 使用可能な予備。前のめりの演技を優先して2を採用 |
