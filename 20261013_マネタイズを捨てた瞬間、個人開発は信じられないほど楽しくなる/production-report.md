## 制作内容

1. 採用3本を `video/tools/key.py` で背景分離し、30fps の RGBA 連番（WebP）にした。緑は g−r の差で抜き、あご下・腹部の緑かぶりは穴埋めと緑の抑制で補正。原本の床影と足元の影のかけらを除き、接地影は編集で作った。手先（画面左側の手）の位置をコマごとに記録
2. three.js（@remotion/three）で文字・図形・切り抜きを同じ座標系へ配置。カメラの移動・ロール・拡縮をカット表の値から組み、読む間も画面全体と1文字ずつの揺れを止めない
3. カット4: M2 の手先の軌道から道具とつまみの位置を決め、手先が届いた所でつまみが押され、反応（14.70秒）とともに輪が「自分」へ走る。カット7・8: M3 の手先に合わせてつまみが動き、手の速さに応じて道具が弾む
4. BGM を Python で合成し（理由と構成は video/README.md）、エンドロゴは原本 SVG のアニメーションをフレーム計算へ翻訳したもので組み込んだ

画面の文言はカット表どおり。カット7の「『楽しい』を大きく出す」は、画面文言「作る楽しさが戻ってくる」の「楽しさ」を2倍で強調し、回転・拡大して奥へ抜く形で実装した（カット表にない「楽しい」という文言は加えていない）。

## 確認したこと（実施した範囲）

- 動き: 完成動画の0.5秒ごとの一覧（本編・ロゴ）と、11か所の場面間を0.1秒刻みで目視。隣接フレームの差による検査で本編45秒に静止区間（0.5秒窓の平均差<0.6）なし。初回の書き出しで35–39秒と44秒付近が静止気味と判定し、カメラ・文字・背景の輪の動きを強めて解消
- 文字の外周5%: 0–45秒を0.25秒刻み（180コマ）で全文字の位置を検査し、違反0件（最終版の文字配置で実施）
- 切り抜き: 4区間の代表コマを墨色・生成りの上で原寸確認。緑の縁・体の欠けは見当たらず。M1 の足元に残っていた影のかけらは除去済み
- エンドロゴ: 原本 SVG の CSS アニメーションを Chrome で各時刻に止めた画と、翻訳版を0.1秒ごと55時刻で比較し、差の画素は最大0.11%。パス・キーフレーム値・イージングの文字列照合も全一致。完成動画で45–50.5秒を一覧確認し、49.0秒以降は完成状態を保持
- 音: 11.03–11.27秒の音声サンプルが全て0（境目の数ミリ秒は AAC の符号化による微小な漏れ。−29dB 以下）。49.2秒からフェードし、50.3–50.5秒は −68dB。統合ラウドネス −14.0 LUFS

## 未確認・注意

- **BGM と映像の相性は、私自身が音として聴いて確認できていない。** 確認したのは波形・音量・無音区間・アクセントの時刻（映像の出来事の時刻から配置）まで。冒頭・カット4・カット7〜8を等速で再生して試聴し、曲調が合わなければ指摘してほしい
- 動画全体の等速での通し再生による目視は行っていない（コマの一覧・場面間の0.1秒刻み・動きの量の数値で確認）
- 書体の幅を正方形で近似した検査のため、文字の外周検査はやや厳しめの判定
