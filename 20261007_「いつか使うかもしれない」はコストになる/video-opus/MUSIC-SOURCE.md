# BGM 来歴 — 「いつか使うかもしれない」はコストになる

- ファイル: `public/bgm.mp3`（256kbps, 映像に使用）／`public/bgm.wav`（44.1kHz/16bit ステレオ原本）
- 長さ: 78.000 秒（映像の確定尺 78.0 秒＝2340 フレームを全尺で覆う。末尾 1.4 秒はフェード）
- 制作: 本企画専用に **ローカルで新規合成**（`audio/bgm_build.py`、Python 3.13 + numpy 2.5.3 + scipy 1.18.1、ffmpeg で mp3 化）。
  外部音源・サンプル・ループ素材・生成AI音楽サービスは不使用。過去企画（20261007 ガント作品ほか）の曲・波形・フレーズは流用していない。
- 費用・クレジット消費: なし。利用条件: 自作のため制約なし（第三者の権利を含まない）。
- 構成（120BPM、1小節=2秒、`src/lib/structure.json` を映像と共有）:
  | 区間 | 映像 | 音楽 |
  |---|---|---|
  | 0–10s | 雪崩れ | 低いドローン→2sからキック、16分ハットとプラックのアルペジオがフィルタを開きながら増える、10s へライザー |
  | 10–22s | 圧縮 | 4つ打ち＋クラップ、8分でポンプするベース、裏拍のコードスタブ。ベース・スタブ・パッドのフィルタが小節ごとに閉じる（圧迫）。12/14/16/18/20s の小節頭に低い衝撃（映像の圧縮の段と同期）、21.5s で停止し逆再生スウェル |
  | 22–34s | 裏返し | 22s インパクト＋クラッシュ→ハーフタイム、FMベルの問いの主題、28.0s の本の開ききりにヒット |
  | 34–54s | 隙間→前進→整列 | Dm→F–C–Dm–Bb の明るい進行、シンコペーションのベース、オープンハット、リード。46–48s スネアロール→48s 整列ヒット、50s クラッシュ |
  | 54–66s | RAG の留保 | 54–58 推進、**58–62s は低音とキックを抜いて疑問の間**（「それでも、まだ届かない」）、62s で戻る |
  | 66–78s | 結論 | 全パート＋1オクターブ上のリード、76s 最終ヒット（Fadd9 を散らしたベル）を残響で着地 |
- 技術チェック（`audio/analyze.py`）: 全編 78.0s、ピーク -1.0 dBFS（AAC 化後 -0.36 dBFS）、クリップ 0、2秒ごとの RMS はおおむね -11〜-13 dB（58–62s は意図的に -16 dB、冒頭 0–2s は -26 dB から立ち上げ）、無音ブロックなし。
- **試聴: 未確認。** モデルは音声を聴取できないため、音色・ノリ・映像との主観的な相性は確認していない。上の数値は試聴の代わりではない。ユーザーによる冒頭（0–22s）・中盤（34–54s）・後半（54–78s）の試聴で採否を判断してほしい。
