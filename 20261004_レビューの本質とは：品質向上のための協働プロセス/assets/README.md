## 用途と限界

- K01〜K06は**演技・美術・画角の基準画**。背景と手が一体の画像で、分離済みのアニメーション用リグではない。
- K01／K04／K05／K06のページが空白なのは、内側の絵を独立して作画・合成するため。空白のまま上映する指定ではない。
- P00〜P04は**内側の状態見本**。時間を表す中割りは別途必要。P00は形の不整合、P02は接続不良を意図的に描いている。
- P03は受け手の手が早く下がった瞬間。静止画だけでタイミングの原因を説明できたとはみなさず、P01からの動きと合わせて検証する。
- 全画像は不透明。透過素材として重ねない。実制作では紙色を合わせた合成・前景の指マスク・ページ変形を設計する。
- 同じ参照から制作したが、人物の輪郭や木目に微差がある。画像を順に切り替えて連続動作の代用にしない。一つの背景とキャラクター設計を基準に動画用パーツを作る。
- K05ではAが鉛筆を持つので、机の下に置いていた鉛筆はない。K06では戻っているため、間に「鉛筆を置く」動作を入れる。
- K02からK03へ、承認印は表紙に残る。開いた後の本文には印を転写しない。

## 今回の検品

- 新規生成と既存生成画像を参照した編集を使い、同じ机、左綴じ、上左からの光、袖の配色を維持した。
- 全11点を目視し、手・カップの個数、役割、背景・画風を確認。圧縮後も画像を開いて代表的な輪郭・指・カップの分離を確認。

- アニメーションの接触やフレーム間の連続性、観客による理解は未検証。詳細は`../feedback.md`末尾。
