## BGM・効果音

Python で合成（`video/audio/bgm.py`、固定シード）。前作の曲は流用していない。音楽生成サービス（Lyria）と比べた理由: 取り消し線・Roll・札の叩き込み・吹き出しの停止・「知らん。」・「移った。」など約40か所へフレーム単位で合わせる必要があり、ローカル合成が速く確実で費用もかからないため。D 長調の軽いポップで、06 の直前で一度引き、吹き出しが迫るのに合わせて上がり、07 が最速、10 で開いてロゴの保持の終わりで収まる（曲調・編成は `video/README.md`）。BGM 単体は −13.0 LUFS。BGM は全体 −8 dB、声のある間はさらに −9 dB 下げて混ぜた。

**試聴は未実施。** 曲の雰囲気がブリーフに合うか、声との音量の比は耳で確認していない（2秒ごとの音量の推移で、06 の引き（−23 dB）と 10 の開き（−11 dB 前後）が意図どおりに出ていることだけ数値で確かめた）。

## 実装

- 文字は DOM／CSS（行のマスク、詰め組）。three.js は不採用（理由は `video/README.md`）。
- 動きは行・語の塊・札・円・画面全体の移動／拡縮／回転で出し、字形は揺らさない。01 の Dolly out、02 の 90° Roll（01 の文が倒れ 02 の文が起き上がる）、03 の語が抜けるたびに縮む円、04 の円の窓が大窓へ広がる動き、06 の加速する Dolly in と押し戻し、07 の字の窓が吹き飛び朱の 2 行が反対側から入る受け渡し、08 の札が点へ縮んで線でつながる動き、09 の 2 円の回り込み、09→10 の円から窓への寄りを入れた。
- 素材動画 3 本は使用区間で切り出し、共通参照画像に色の平均を合わせた（y30）。04 と 10 は窓が見えている時間に合わせて 0.6 倍速・0.84 倍速に伸ばした（企画は 04・10 の速度を指定していない。ループ・静止なし）。07 は企画のとおり等速で、素材が終わる前に字の中を灰で埋めて止まった画を見せない。
- 企画の「読む間は行ごとに逆向きにゆっくり流す」（05・07）は、過去の評価（行のゆっくりした流れ・画面全体の漂いに違和感）に合わせ、常時の流れではなく、左右逆向きからの入りと、声の区切りでの一段の寄り（Push in）に置き換えた。
- エンドロゴは 20261018 で原本 SVG と照合済みのフレーム翻訳をそのまま使った。

- 文字の検査（`node render.mjs check 0.25`、画面外と線・矢印・点との重なり）: 03 の「AIへ」の右端の食い込みと 05 の最後の寄りで「影」が左の余白に入る点を直した。残る検出は次のとおりで、いずれも意図した動き。

- 検査の対象は文字（`data-ch`）と線・矢印・点（`data-fig`）。円・素材の窓・吹き出しとの重なりは機械では見ておらず、コマの目視による（円の中の文字・窓の上の札は意図した配置）。
