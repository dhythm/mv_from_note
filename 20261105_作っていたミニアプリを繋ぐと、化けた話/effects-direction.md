## 入力（一般化した作品説明）

- 作品：小さな道具を1つずつ作り、それぞれがきちんと動くようにしておくと、後でつないだときに大きな仕事を動かせる、という筆者の経験を約 2 分で伝えるキネティックタイポグラフィの動画。明るい紙色の画面。
- ねらい：凹凸（入口と出口）のついた青い小さなブロックが、1つずつ置かれ（小さく作る）、1つずつ光の粒を受けて出し（ちゃんと動く）、最後に出口と入口が噛み合って粒が流れ、ズームアウトで1本の線になる（つなぐと変わる）。脇役として、全部が1つの塊に潰れてひびが入る対比を1回だけ見せる。

## 不採用と理由

| 効果（ID） | 理由 |
|---|---|
| 画面がガラスのように割れる（t03_shatter） | 画面全体が割れると「場面の切り替え」に読める。割れるのは合体した塊だけにしたいので g18 を塊の上に限定して使う |
| 立方体が字に組み上がる（t12_voxel_type） | 小さな立方体が集まって 1 つの字になる＝「合体」の絵になり、主張（合体させずにつなぐ）と逆 |
| 粒子が形から形へ変わる（t01_particle_morph） | コマが溶けて別の形になると、「一つひとつが残る」ことが見えなくなる |
| 落ちて積み重なる（p16_physics_pile） | 偶然積もった印象になる。10 の「積み重ねた経験」は 1 つずつ置く動きで見せたい |
| ばねでつながる字（p23_spring_text） | 字が揺れ続け、読む間の可読性が落ちる（AGENTS.md：字形は崩さない） |
| 流れに沿う線（p19_flow_field）／枝分かれして育つ線（p18_growth） | 流れが無数・枝分かれになると「1本の線（ひとまとまりの仕事）」がぼやける |
| 回転寿司のレーン（t79_sushi_lane） | レーンで回る絵は「順に流れる」には合うが、皿を取ると穴が開く意味が加わり、記号が増える |
| 数字が回って止まる（s14_counter）／数字のグラフが伸びる（s86_growing_charts） | 原稿に数値の指標がない。数字を作らない |
| 流れる帯の字（s22_marquee） | テロップ帯に見える。テロップ帯は入れない方針 |
| 光のにじみ（t06_bloom_neon） | 粒を光らせすぎると明るい画面で滲み、オレンジの粒の意味（仕事の流れ）より飾りが勝つ |
