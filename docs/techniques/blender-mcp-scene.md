# Claude Code × Blender MCP で 3D シーン素材を作る手順

出典: ハヤシモン（@hayashimon1）のスレッド「深夜のコインランドリー」 https://x.com/hayashimon1/status/2108913484805406859
動画の素材づくり（背景・雰囲気カット）に使う手順。実行するのは企画側が Previs やシーン素材を用意するときである。制作側へ渡し、不足した画像・動画の新規生成を任せる文書ではない。足りないカットは、必要な内容を企画側へ戻す。

## 前提
- Claude Code に Blender MCP を接続し、Blender を直接操作できるようにする。
- 精度の高いモデルを使う。
- 完成イメージ用の画像生成ツールは何でもよい。
- 一度に全部作らず、大枠から細部へ段階を分ける。人は良し悪しの判断と指示に徹する。

## 手順
1. 完成イメージの2D画像を作る（雰囲気・構図・配置の参考）。
2. 画像を渡し「このイメージで〇〇を Blender で作成」と指示し、レイアウトを空間として組ませる。
3. 空間 → モデル → 質感の順で精度を上げる。
   - ブロックアウト（箱だけの簡易空間）から始める。
   - ブーリアンで穴を開けて奥行きを出す、布シミュレーションで布の形を作るなど、細部を足す。
4. 質感はプロシージャルで作る（画像テクスチャは使わない）。
   - エッジの塗装剥げ、隙間の汚れ、上面の埃、床際の汚れ、垂れ跡、指紋を1つのノードグループにまとめる。
   - それを全マテリアルに強さを変えて重ねる。
5. 看板・ステッカーは「印刷物」として作る。
   - 3D文字を直接並べるとCGっぽくなるので避ける。
   - Blender 内で2Dデザインを組み、真上からレンダリングしてテクスチャにする。
   - 退色、黄ばみ、ラミネートの艶、剥がれを重ねる。
6. ダメ出しで詰める。「看板の余白が多い」「床をもっと参考画像に近づけて」など具体的に伝え、クローズアップで1つずつ直させる。
7. アニメーションと最終ディテールを足す（例: 回転物、照明の不規則な点滅、風で揺れる窓、雨、ゆっくり前進するカメラ）。
8. 「レンダリングして mp4 にして」で書き出す。

## ポイント
- 進め方: 空間 → モデル → 質感の順に段階を分ける。
- 質感: プロシージャル中心。汚れ・摩耗はノードグループで統一管理する。
- 看板類: 3D文字ではなく、2Dレンダリングした印刷物に劣化表現を重ねる。
- 人の役割: 判断と具体的な指示。細かい修正はエージェントに任せる。新しい画像・動画をこの手順で作るのは企画側。本編の実装担当へ、不足素材の生成として渡さない。
- 一度に完璧を目指さず、フィードバックを繰り返す。
