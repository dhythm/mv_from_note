# タイポグラフィー中心のモーショングラフィックス部品

制作側が Remotion で文字を主役にした動画を組むときの出発点。実装は `20261018_その資料、担当者の上司が読んでも通じますか？/video/src/v2/kit.tsx`。新しい作品では、このファイルを写して配色・書体・寸法を作品に合わせる。前作の場面ファイル（`scenes*.tsx`）や絵柄を流用の出発点にしない。

## 型（何をどの層でやるか）

| 層 | 中身 | 動かし方 |
|---|---|---|
| 文字 | 主張の言葉（1カット1〜2行が目安。大きさの対比を強く、104〜250px・太さ900） | 行のマスクから1文字ずつせり上がって入り、上へ抜ける（`Line`）。読む間は行ごとに逆向きへゆっくり流す（`slide`）。形は崩さない |
| 図・人物 | 資料、札、矢印、吹き出し、採用動画、静止姿勢 | `Cam`／`Lay` で寄り・回転・押し出し。カメラの寄りはこの層にだけ掛ける |
| 画面全体 | 背景の色の面 | 色の面のワイプ（`Wipe`）、円の拡大（`Iris`）、ゆっくりした漂い |

- 文字は DOM／CSS で組む。`fontFeatureSettings: "palt"` で詰める。強調の印は文字単位の背景で引き（`Line` の `mark`）、位置を目測で置かない
- 色は意味の語にだけ付ける（例: 紫＝読み手の問い、青緑＝口頭、黄色の印＝残す情報）
- 矢印・吹き出しは一つの SVG の輪郭で描く（`ArrowSvg`、`Bubble`）。線と短冊のつなぎ合わせ、四角を回して重ねた尾は使わない
- 場面の転換は色の面・押し出し・寄りで渡す。意味のない波紋・火花・速度線は足さない
- 採用動画は、文字の意味と同じ拍の動作だけを使う。文字に場所を譲る位置と大きさに置く

## 進め方

1. 作品の書体・配色・文字の大きさの段階を先に決める
2. 代表の1区間（20秒前後）を作り、等速の動画でユーザーに見てもらう
3. 了承を得てから全編へ広げ、静止画で文字と図の重なりを確かめる

動きの量の数値（フレーム差分）は静止区間を探す道具にとどめる。合格の判断には使わない（`AGENTS.md`「動きの強さ」）。
