## 表現の方針（現行版）

- **文字が主役。** 各カットを1〜2行の大きな言葉（104〜250px、太さ900、詰め組 palt）で組み、意味のある語だけに色を付けた（紫＝読み手の問い、青緑＝口頭、黄色の印＝残す情報）。図・人物・動画素材は、言葉の意味を支える位置と大きさに置いた
- **文字の動き。** 行ごとのマスクから1文字ずつせり上がって入り、マスクの上へ抜ける。読む間は文字の形を崩さず、行ごとに逆向きへゆっくり流す。画面全体はゆっくり漂わせた。場面の転換は、色の面（紫・濃紺・薄紫・ライム）、押し出し、寄りで次へ渡した
- **層を分けた。** 文字の層と図・人物の層を分け、カメラの寄りや回転は図・人物の層にだけ掛けた。文字が画面外へ切れたり、図の下に隠れたりしないようにした
- **図形は一つの輪郭で描いた。** 矢印は線と先端を一体の SVG で、吹き出しは本体と尾を一つのパスで描いた
- 意味のない飾り（波紋・火花・速度線）は使っていない

## three.js の採否

現行版では使っていない。文字を主役にするには、行ごとのマスク、詰め組、くっきりした字面、文字ごとに正確な黄色の印が必要で、DOM／CSS の方が品質と実装の確実さで勝ったため。奥行き（札のめくり）は CSS の 3D 変形で出した。すべての動きはフレーム時刻から計算している。初版は three.js で作り、文字をテクスチャとして字幕のように重ねた。これが品質低下の一因になった（feedback.md）。

## BGM

Python で合成した（120BPM、D–A–Bm–G、動くベース・鍵盤・プラック）。作り直した映像の出来事（文字の着地、ワイプ、押し出し、07 の静止、12 の着地など約80か所）に合わせてアクセントを置き直した。07 の「話が止まる」では 52.6–53.0 秒を無音にしている。音楽生成サービスと比べ、映像の出来事へフレーム単位で合わせられることと、費用がかからないことから選んだ。打楽器と効果音の音色関数は 20261015 の `bgm.py` のものをそのまま使っている。テンポ・調・和声進行・編曲と、プラック・鍵盤の音色は今回の新規。

## 確認したこと（実施した範囲）

- 代表区間: 01–03（0–22秒）を全編より先に等速の動画で書き出し、ユーザーに見てもらって方向の了承を得た
- 静止画: 04–15 の代表時刻（38時刻）を書き出し、文字と図・人物の重なり（05・10・11・13）と、行の入れ替わりの重なり（07）を修正した
- 全編: 1秒ごとの一覧（153コマ）を目視した。0.5秒窓の動きの量（平均差0.3未満）では、本編で閾値を下回るのは次の区間だけ：場面の切り替えの瞬間（10.5・109秒）、06 の問い返しを待つ間（39–41秒）、12 の連結のあと（102.5–103.5秒）、13 の問いの間（115.5秒）。ただし動きの量は合格の基準にしていない。一覧で静止画の切り替えに戻っていないことと、読みやすさを見た
- 仕様: 4590フレーム・30fps・1920×1080、音声 AAC 48kHz ステレオ・153.0秒。統合ラウドネス −14.1 LUFS
- エンドロゴ: `tools/check_logo.py` で原本と一致（all_ok）。`Logo.tsx` は照合済みのファイルから変えていない。一覧で o の落下→スライド→.work の出現と、完成形の保持を確認した。`logo_compare.mjs` の画素比較は今回再実行していない
