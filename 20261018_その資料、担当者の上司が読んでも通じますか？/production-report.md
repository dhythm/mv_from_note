## 制作内容

1. 採用動画3本（透過WebM）を、透過を保ったまま1コマずつのPNGにし、three.js のテクスチャとしてフレーム番号から再生。基本の1.5倍速。明るい背景に合成して緑の縁が残らないことを画素で確認した
2. 共通キャラクター参照から10姿勢を、絵コンテと同じ座標で切り出し。動画内の人物と静止姿勢を同じ高さ・同じ頭の位置で置けるよう換算し、静止姿勢→動画の切り替え（05 の歩き出しから受け渡しへ）で大きさが跳ねないようにした
3. 01 と 05 は同じ受け渡しの素材を、構図（人物の高さ 560px と 430px）と前後の流れ（01 は問いと横の運び、05 は会議の場から歩き出て受け渡し）を変えて使った
4. 06・07 は問い返しの素材を原本 0–2.5 秒／2.5–6 秒に分けて使い、動作のあとは最後のコマで止めたまま、紙面への寄り・問いの回り込み・説明の線のつまずき・欠けの拡大で画面を動かし続けた
5. 07 の「そこで、話が止まる。」で、画面全体（カメラ・文字・図）を0.42秒だけ止め、同じ区間の音を抜いた。その後、欠けた理由の欄が前面へ拡大する
6. 12 は理由の札が奥からカメラの近くを横断して目的と進め方の間へ着地し、縦積み→横一列へ組み替え、連結線が拍に合わせて伸びる（後半の見せ場）
7. BGM を Python で合成（120BPM、D–A–Bm–G、動くベース・鍵盤・プラック、約50か所のアクセント、07 の抜き、12 の着地、ロゴの終了で収める）。音楽生成サービスと比べ、映像の出来事へフレーム単位で合わせられることと費用がかからないことから選んだ。なお打楽器と効果音の音色関数（キック・スネア・クラップ・ハット・ベース・インパクト・ヒュー音・ライザー・鈴・パッド）は 20261015 の `bgm.py` のものをそのまま使っている。テンポ・調・和声進行・編曲・プラックと鍵盤の音色は今回の新規
8. エンドロゴは 20261013・20261015 と同一の `Logo.tsx`（原本SVGのアニメーションをフレーム計算へ翻訳）を幅1500pxで中央に配置。15 の終わりにライムの面で本編を払い、148秒までに覆い終える

画面の文言は企画書のカット表に従った。絵コンテにある補助の語（「担当者」「上司」「会議の場」「会議には不参加」「経緯を共有」「口頭の補足」「説明は？」「理由は？」「目的」「結論」「説明の線が、つながらない」「手法の名前」「何をする手法か」「説明を飛ばす ＝ ページを消す？」「話すときは飛ばせる」「必要なページは残る」「その場の相手へ」「その先の読み手へ」「要点」「話す内容を削る」「必要な情報を残す」「候補 A・B・C」「選んだ B」「理由の欄がない」「他のやり方は？」「理由が、後ろに離れている」「なぜ、ここだけ違う？」「境目は？」「資料に足す一行」「当日、答えを用意する」「この違いの意味は？」「今回の範囲」「記録」「報告」と各札）は絵コンテに合わせて使った。10 の「口頭で話す情報」の下の「経緯・前提・細かな手順」は、04 の「経緯」と口頭の補足を受けた補助の語として加えた。06 の吹き出しは、絵コンテの「なぜ、この方法？」ではなく、画面の文言「なぜ、このやり方？」に揃えた（同じ問いが二つの言い方で並ばないように）。12 の他の候補は「候補A」「候補C」の札と一言を示す短い線で表した。

元記事の全文は今回読み直していない。画面の文言は、企画段階で原稿と対応づけた plan.html・references.md のものをそのまま使った。

## three.js の採否

採用（@remotion/three）。人物・資料・札・文字を同じ3D空間に置き、カメラの移動・ロール・ズームと文字層の独立した運動で、読む区間にも画面全体を動かした。すべての動きはフレーム時刻から計算している。

## 確認したこと（実施した範囲）

- 代表区間: 05–07（30–57秒）と 10–12（74–109秒）を全編の前に等速で書き出し、2コマ／秒の一覧と0.5秒窓の動きの量で確認。06 の引き（39秒）と 12 の冒頭（97–99秒）・連結後（103.5–104秒）の動きが弱かったため、カメラの運動と構図を強めてから残りのカットへ展開した
- 静止画: 各カットの代表時刻を書き出し、文字と人物・資料・弧の重なり（01・03・06・09・10・14・15）を修正
- 全編: 1秒ごとの一覧（153コマ）を目視。0.5秒窓の動きの量で、本編0–148秒に閾値（平均差0.6）未満の窓はない。閾値未満はエンドロゴの区間（148秒以降。ロゴの規定動作と完成形の保持）だけ
- カットの境目: 8・15・22・30・38・47・57・67・74・86・97・109・122・133・148 秒の前後0.6秒を10コマ／秒で確認。白コマや大きさの跳びはない。57（07→08）と 67・74 の入り口では、寄りの直後に要素が少ない0.1–0.3秒がある（振りの途中）
- 仕様: 4590フレーム・30fps・1920×1080、音声 AAC 48kHz ステレオ・153.0秒
- エンドロゴ: `tools/check_logo.py` でパス・キーフレーム値・イージングが原本と一致（all_ok）。`Logo.tsx` は 20261015 の照合済みファイルとバイト単位で同一。今回 `logo_compare.mjs`（原本SVGとの画素比較）は再実行していない。一覧で 148–151 秒の o の落下→スライド→.work の出現、152 秒の完成形を確認
- 音: 統合ラウドネス −14.0 LUFS。52.62–53.0 秒は無音（07 の静止と同じ区間）。12 の着地付近（100–103秒）は −8.5 dB、07 の前後は −10.5／−12.0 dB（RMS）。152.2–152.6 秒 −39 dB、152.8–153 秒 −69 dB でロゴ終了に収まる
