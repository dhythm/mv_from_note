# 制作プロジェクト（Remotion＋three.js）

[企画書](../plan.html) に従って作った動画のプロジェクト一式。完成版は `../renders/final.mp4`（1920×1080・30fps・153秒＝4590フレーム、H.264／AAC 48kHz ステレオ。Git 管理外）。

20261015 の制作プロジェクト（three.js の舞台・文字の部品・エンドロゴ・書き出しと点検のスクリプト）を土台に、配色・カット・素材の再生・BGM をこの作品用に作り直した。

## 再現手順（このフォルダで）

1. Node.js・Python 3・ffmpeg を用意し、`npm ci`、`python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`、`npm run prepare:assets`（フォント・ロゴをリポジトリ内の原本から `public/` へコピー）。
2. 素材: `sh tools/extract_clips.sh`（採用動画3本の透過WebM → `public/clips/<id>/NNNN.png`。透過を保つため VP9 デコーダを明示）、`.venv/bin/python tools/crop_sprites.py`（共通キャラクター参照 → `public/sprites/` の10姿勢）。どちらも企画側の原本から再生成できるため Git 管理外。
3. BGM: `.venv/bin/python audio/bgm.py` → `audio/bgm.wav`、`public/bgm.m4a`（固定シード）。
4. 全編: `node render.mjs full` → `out/final.mp4`（スチル `node render.mjs stills 0.4 10,20`、区間 `node render.mjs range S E name 0.5 [1]`）。
5. 点検: `npx tsc --noEmit`、`.venv/bin/python tools/review.py out/final.mp4`（1秒ごとの一覧と動きの量）、`.venv/bin/python tools/motion.py <区間動画> <開始秒>`、`.venv/bin/python tools/check_logo.py` と `node tools/logo_compare.mjs`（エンドロゴを原本SVGと照合）。

## 構成

- `src/timeline.tsx`: カットの時刻表（01 0–8／02 8–15／03 15–22／04 22–30／05 30–38／06 38–47／07 47–57／08 57–67／09 67–74／10 74–86／11 86–97／12 97–109／13 109–122／14 122–133／15 133–148／16 ロゴ 148–153）。
- `src/cuts.tsx`（05–07・10–12 と共通の動きの道具）、`src/cutsA.tsx`（01–04・08–09）、`src/cutsC.tsx`（13–15）: 各カットは時刻からカメラ（画面全体の移動・ロール・拡縮）、HUD（主張の文字）、世界（人物・資料・札）、画面固定（速度線・ライムの払い）を返す純関数。
- `src/parts.tsx`: 二人のピクト（静止姿勢・採用動画）、資料、札、吹き出し、破線の枠、会議の場。色の意味は企画書「配色と記号」のとおり。
- `src/components/stage.tsx`: three.js の舞台。採用動画は1コマずつの透過PNGをテクスチャとして読み、フレーム番号から再生する。
- `src/components/Logo.tsx`: エンドロゴ（20261013・20261015 と同一ファイル）。

## three.js の採否

採用（@remotion/three）。文字・人物・資料・札を同じ px 座標の3D空間に置き、カメラの移動・ロール・ズームと文字層の独立した運動で画面全体を動かす。会議の場の後退（05）、紙面への寄り（06）、二つの空間の開き（10）、候補の巡回（11）、理由の札の横断（12）は奥行きを使う。すべての動きは `useCurrentFrame` から計算し、実時間・順序依存の乱数は使っていない。

## 素材の使い方

人物の大きさは、動画内の人物（頭頂〜足元 約460px／720px、担当者の頭の中心 x=396、上司 x=876、足元 y=621）と静止姿勢を同じ高さで置けるように換算している（`parts.tsx` の `clipGeom`）。動画は反転していない。再生範囲を過ぎたら最後のコマで止め、ループ・引き伸ばしはしない。

## BGM

Python（numpy/scipy）で合成。音楽生成サービスは使っていない。理由: 映像の出来事（受け渡し、問いの着地、07 の静止、12 の札の着地など約50か所）へフレーム単位で合わせる必要があり、ローカル合成が速く確実で費用もかからないため。

- 120BPM・4拍子（0秒起点、映像の拍と同じ格子）。D–A–Bm–G、問いの区間（07・11）は Bm–G–D–A
- 乾いたキック・スネア・クラップ・ハット、8分で動くベース、小節頭の鍵盤、2・4拍の裏のプラック
- 07 の「話が止まる」で 52.6–53.0 秒を無音にする（映像も同じ区間だけ静止）
- 12 の着地（101.3 秒）に最大のアクセント、連結線に鈴
- エンドロゴの o の着地・スライド・.work に軽いアクセント。151.9 秒からフェードし、153 秒で収める
- 統合ラウドネス −14 LUFS

## 保存対象

制作ソース・設定・依存関係の固定情報・生成／点検スクリプトを Git 管理する。素材のコマ・スプライト・生成音源・原本からコピーするフォントとロゴ・書き出し・確認画像・キャッシュは管理対象外。完成動画は `../renders/final.mp4` にローカル保存する。
