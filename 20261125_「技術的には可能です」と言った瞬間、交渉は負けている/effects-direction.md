# 演出の適合確認

確認日：2026-11-25。[NANKA DEKIRU](https://esoragototv.com/tools/nanka-dekiru/index.html) の `catalog.json`（156件。カタログの更新日は 2026-10-06）と、プロンプトビルダーの `writeOut`（`index.html` 内の関数）を読んだ。二つの欄は「作品・場面」と「ねらい」で、選んだ見本の作り方と連結して指示文になる。非公開原稿は入れていない。見本の全ループを等速で連続視聴したとは扱わない。下の採用と不採用のうち、ソースを読んだものだけを「ソースで確認」と書く。

## 入力する一般化した説明

- 作品・場面：明るい紙色の机。言葉が札になり、机を滑って相手側で別の面に裏返る。棚の上の品と矢印で、並べたものが欲しいものに変わる。
- ねらい：文字の形は崩さない。動かすのは札、棚、矢印、語の塊、図のカメラ。札へ2秒寄り、その直後に0.4秒の短い振りで相手側を見せる。

ページが生成する章表示、固定手順、了承を得てから作り始める段は採用しない。

## JIZURA の語彙

[JIZURA](https://github.com/852wa/JIZURA) は歌詞から文字の映像を組むブラウザアプリ。利用は必須ではない。ここではアプリを動かしていない。参照したのは、このリポジトリのスキルが v0.13.0 の README からまとめた部品名だけである。非公開原稿は入れていない。NANKA DEKIRU の確認の代わりにはしていない。

- ゆっくり寄る：03のドリーインの言い方の参考。カメラは札と机の層だけに掛ける。
- ワイプ：語の塊が行のマスクから入る。1字ずつではない。
- ドリフト：読むあいだ、語の塊や棚の層をゆっくり流す。字形の揺れにはしない。
- プッシュ：08の結びで、語の塊を寄せてから、ライムの全面へ横に振る。

採らない部品はジッター、グリッチ、爆散、拍ごとの脈動、飾りの数字。文字の形を崩すものと、意味のない飾りである。

## 制作への引き渡し

plan.html には、棚と矢印で並べたものが欲しいものに変わること、札が2秒の寄りと0.4秒の振りで相手側の「やる前提」に裏返ること、法外な金額の束は崩れ、費用より理由が手前に出ること、柱は期間の印に届かないこと、結びは本人の結論で閉じることを記載した。見本のコード・画像・音は転載しない。仕組みはフレーム時刻から決まる実装へ翻訳する。最初の試作は02と03で、矢印が語に重ならないこと、寄っているあいだ文字が読めること、ホイップパンで文字の層をぼかさないことを等速で確認する。
