確認日：2026-11-26。[NANKA DEKIRU](https://esoragototv.com/tools/nanka-dekiru/index.html) の `catalog.json`（2026-10-06 更新のカタログ）と、プロンプトビルダーの欄が「作品・場面」と「ねらい」であることは、同日の見本ページから読んだ。非公開原稿は入れていない。見本の全ループを等速で連続視聴したとは扱わない。下の採用と不採用のうち、ソースを読んだものだけを「ソースで確認」と書く。

## 入力する一般化した説明

- 作品・場面：明るい紙色の机。文の主語、目的語、述語が色の違う札になり、中央の「私」が文頭へ滑って、述語の札の面が別の言葉に替わる。
- ねらい：文字の形は崩さない。動かすのは札、札の列、語の塊、図のカメラ。札の「私」へ2秒かけてゆっくり寄り、組み替わった瞬間に0.5秒で奥の札だけをぼかす。

ページが生成する章表示、固定手順、了承を得てから作り始める段は採用しない。

## JIZURA の語彙

[JIZURA](https://github.com/852wa/JIZURA) は歌詞から文字の映像を組むブラウザアプリ。利用は必須ではない。ここではアプリを動かしていない。参照したのは、このリポジトリのスキルが v0.13.0 の README からまとめた部品名だけである。非公開原稿は入れていない。NANKA DEKIRU の確認の代わりにはしていない。

- ドリーイン：03で「私」の札へ寄る言い方の参考。カメラは図の層に掛ける。「私」と「学ぶ」の文字は正面のまま読む。
- ワイプ：語の塊が行のマスクから入る。1字ずつではない。
- ドリフト：読むあいだ、列や語の塊をゆっくり流す。字形の揺れにはしない。
- プッシュ：08の結びで、語の塊を寄せてから、ライムの全面へ横に振る。

採らない部品はジッター、グリッチ、爆散、拍ごとの脈動、飾りの数字。文字の形を崩すものと、意味のない飾りである。

## 制作への引き渡し

plan.html には二列の差で主体と受動を見せること、札が2秒の寄りと0.5秒のピント送りで「私が 学ぶ」に組み替わること、情報の札が「使う」と「使わない」に分かれること、基礎の短い塊の横で高い列の一節だけに手伝いが付くこと、結びは本人の結論で閉じることを記載した。見本のコード、画像、音は転載しない。仕組みはフレーム時刻から決まる実装へ翻訳する。最初の試作は03で、寄っているあいだ「私」が読めること、ピントを外すのが「先生」の札とその文字だけであることを等速で確認する。
