# 「そんなの、そのうちできるようになる」前にチャレンジすることに価値がある

- 原稿: dhythm/private-note `Zettelkasten/PermanentNote/20261006_「そんなの、そのうちできるようになる」前にチャレンジすることに価値がある.md`（note.com からは取らない。作業者は必ず原稿を読む）
- ディレクトリ: `20261009_「そんなの、そのうちできるようになる」前にチャレンジすることに価値がある`（元記事タイトルと一致）
- 企画名（社内呼称）: 技術が解決する前に、試す経験を積む

## 最初に分けること

維持するもの
- 主張: 技術が解決する前に試すから試行錯誤が生まれ、その経験はAIに代われない。便利なものに食われる前に、自分でチャレンジしておく。
- 理由: 技術が解決すると、その分だけ経験が減る（打たなくなれば打つ力、書かなくなれば書く力が落ちる）。解けていない課題があるから試行錯誤が生まれる。このチャンスは技術の進歩で減っていく。
- 留保（画面に残す）: 待つのも判断ではある／対応されたら切り替えていい／いらなくなった力もある／その領域はあとで奪われてもいい。
- 筆者の実例は「私の場合」として出す（コードを90%以上書かせようとしていた→今は99%以上、資料作成ではもう困っていない）。一般論の数値にしない。
- 冒頭の引用（「いつか技術の進化が解決してくれるかもしれないけど、やってみる。」）は引用と分かる形で出す。出典名は原稿にないので入れない。
- 形式: 撮影なし、キネティックタイポグラフィ×モーショングラフィックス。画面全体がグワングワン動く。three.js 推奨。

変えてよいもの
- 上映順と配分、画面の言葉、書体、配色、間。最終はクリエイター。
- 尺。約1分58秒＋エンドロゴ5.5秒（v2合計2分3.5秒）（文字量と観察時間で調整。カット5と7の読む時間は削らない）。

提案側の仮説（原稿にはない）
- 「自分で掘る道＝ジグザグの溝と行き止まり」「技術の解決＝あとから敷かれる直線の舗装」「経験＝残った軌跡の形」という図。

## 前作との差

前作（20261008）は時間の話を時計の目盛り・錆・カウントダウンで見せた。今回は時計の針・文字盤は使わない。時間の進みは舗装の波が迫る速さで出す。質感は錆ではなく、掘った土と光る溝、平らな舗装。

## 動きの課題は1つ

**試行錯誤で掘った回り道が、あとから舗装される。それでも手元に「経験」の字として残る。**
- 自分で掘る道はジグザグに進み、行き止まり（×）も残る。「そのうちできる」と待つ側の地面は、まっさらなまま。
- 途中から上に、公式対応やAIの直線の舗装道路が敷かれ、回り道は要らなくなる。乗り換えていいので、負けとして描かない。
- 最後にカメラが引くと、回り道と行き止まりの軌跡が「経験」の字形になっている。待つ側の比較は、この課題について試した跡の有無に限る。終盤では人の優劣を再対比せず、試した軌跡と便利な舗装が共存する画にする。
- 全編、文字群の拡縮・回転・組み替えと地面のカメラ移動を組み合わせる。読む区間も文字自体が構図を動かす。文字は地面の説明字幕にしない。

## 表現方針

- 文字量: 約500字。毎秒約7字は読了の目安。図形の観察時間は別に等速で判断する。
- ナレーション: なし（依頼があれば AGENTS.md の API ナレーション方針に従う）。
- BGM: 企画専用に新規選定。掘る拍（硬いアタック）と前へ進むリズムがあり、終盤で開ける曲。ゆっくりにしない。過去作の音源は使わない。エンドロゴの終わりまで覆う長さに編集。
- 書体: 本文・強い語は同梱の Noto Sans JP（日本語グリフを確認）、冒頭の引用は BIZ UDPMincho、％とコード片は DotGothic16。
- 色: 地面は暗い土色、掘った溝は `#d2ff1a`（エンドロゴの背景色）で光らせ、エンドロゴへ色をつなぐ。
- 入れない: 冒頭の主題宣言の機械的な挿入、末尾の元記事表示、章表示、テロップ帯、文字だけのスライド。
- 生成動画は使わない前提。使う案が出たら対象・尺・回数・想定クレジットを示し、明示承認前はテストもしない。

## v2 制作時の読みと素材

- 文字配置は assets/storyboard-v2/contact-sheet.jpg と各PNG、文の順序・秒は reading-timeline.json。背景だけ動いて文字が静止する実装は不可。文字が移動する範囲を先に確保し、重要文の縮小で衝突を隠さない。

- assets/type/experience-mask.png は終盤で軌跡を集める実装用の白字マスク。新しい文字をフェードしてごまかさず、カット3・7・9と共通の経路を字形上に設計しておく。字形の完成後もカメラの旋回・光の走行を続ける。

- エンドロゴはワイプ完了後から5.5秒。SVG最後の文字は3.32+0.7=4.02秒に完了するため約1.48秒保持する。ワイプにロゴの時間を食わせない。
