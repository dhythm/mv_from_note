## 入力（一般化した作品説明）

- 作品：「プロンプトの技術はもう要らない」という見方に対し、プロンプトは消えたのではなく、裏側の設計・ガイドライン・チケット・周辺の仕組みに潜っただけ、という筆者の考えを約 100 秒で伝えるキネティックタイポグラフィの動画。
- ねらい：画面中央の一行の指示から、カメラが表層の線の下へ Crane down し、何層もの地層（文字の帯）が一行を支えている断面を見せる。中盤は 2 本の円柱（作り込みの厚み）の比較。明るい紙色の画面。実写なしでも成立させる。

## 不採用と理由

| 効果（ID） | 理由 |
|---|---|
| 落ちて積み重なる（p16_physics_pile） | 「ドサッ」と積もるコメディの崩れになる。地層は時間をかけて整えた設計の比喩で、偶然積もった印象と逆 |
| エレベーターの階（t77_elevator_floors） | 箱の中から階を見る視点で、表と裏の断面（一行が支えられている）を同時に見せられない |
| 切り絵の影絵（t65_papercut） | 層が弾けて開閉する情緒的な動きで、層が一行を「支える」因果が弱まる |
| 字が崩れて組み変わる（s13_text_shuffle）／暗号が解ける字（s21_scramble_decode） | ハッキング・正体の発表の意味が出る。「潜った」は崩れではなく沈む動き |
| 数字が回って止まる（s14_counter） | 原稿に比較の本数・点数の数字がない。数字を作らない |
| 流れる帯の字（s22_marquee） | 傾いた帯がテロップ帯に見える。テロップ帯は入れない方針 |
| 3D 空間で動く字幕（t89_subtitle_3d） | 文字を 3D のテクスチャにすると字幕化し、タイポグラフィが主役でなくなる（AGENTS.md） |
| 光のにじみ（t06_bloom_neon）／光の筋（t16_god_rays） | 一行の指示を神々しく見せ、「表は手軽」という主張と逆の印象になる |
| 奥行きで霧とぼけ（y97_depth_fog_focus） | 差し替え素材の背景になじませる案として検討したが、地層ラベルの可読性が落ちる |

## 注意（企画側の判断として制作側に渡すこと）

- 採用した効果の狙いだけを plan.html に書いた。採否のログはこのファイルだけに置く。
- 効果を採用しても、画面全体の大きな動き（Crane・Roll・Dolly・Orbit・Whip pan）は効果と別に必要。
