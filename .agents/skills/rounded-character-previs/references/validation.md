# この一式で確認した範囲

Blender 5.2.2 LTS、ユーザーのM5 MacBook Pro上で、追加インストールなしで確認した。機械固有の実行ファイル位置はCLI引数で渡した。機械可読の要約は [validation.json](validation.json)。

- Python全スクリプトの構文、CLIヘルプ、素材6ファイルのSHA-256照合。
- 承認済み短歩行の独立コピー。別ファイルで原本とbyte一致。同じ出力先への再実行は終了1で上書き拒否。
- 同梱BVHの30fpsサンプリング、標準モードの6フレーム適合、480×270/Eevee16サンプルの6フレーム描画、0.2秒/30fps/H.264 MP4化と全6fデコード。
- 6フレームの最終細分化メッシュ接地・画角検査。中立頂点ハッシュは基準と一致。画角の最小余白約12%、支持足裏差約0.12mm以内。数値を自然さの合格証明とはしていない。
- 中立形状の再構築、成功歩行のコピー、短動作の3ファイルとも2026頂点・2088面・非多様体エッジ0、基準中立頂点と一致。
- 6f＋72fの2ショット統合blendを保存・再読込し、78f・2ストリップ・外部リンクIDなし。
- 独立担当が説明を読んで、GPU/Blender起動なしの再利用依頼を実行。素材照合、独立コピー、上書き拒否、ヘルプと手順の整合を確認した。対象repoの指示は実装担当が別途確認した。

標準の `quick_validate.py` は、既存PythonにPyYAMLがないため実行未完。追加インストールは行わず、システムRubyの標準YAMLでfrontmatterを実際にパースし、必須キー・命名・文字数・未完プレースホルダ・ローカルリンクを別途確認した。このスキルの実行自体はPyYAMLを必要としない。

未検証: パッケージ化した新CLI経由の長い新動作、深い前屈/頭上腕の各分岐の再試験、任意の別リグ、30fps以外のリターゲット、全身の非表示面や動力学、別OS/別Blenderバージョン、次回タスク開始時のカタログ自動再読込。元エンジンの応用例には19.5秒の5動作があるが、その成功を新しい入力すべての保証へ広げない。
