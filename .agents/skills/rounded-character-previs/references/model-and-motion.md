# 形状、リグ、モーション適合

## 中立形状

Blender 5.2.2 LTSで自作した、2026頂点・2088面（1960四角形、128三角形）の閉じた一体メッシュ。首・肩・股・四肢は同じ表面のトポロジーでつながる。三角形の扇は主に頭頂・手先・足裏の終端。`engine/build_character.py` のquad loftと共通境界から再構築する。

## スキニング

`pelvis → chest → head`、左右それぞれ `upper_arm → forearm → hand`、`thigh → shin → foot`。肩・股は体幹の子。体積保持（dual quaternion）ArmatureをSubdivisionの前に置く。

成功版の `refine_skin.py` は、肘 |X| .62±.042、膝Z .60±.045に狭い滑らかなウェイト移行を設け、手首・肩・足首も滑らかにする。腰ではBlender標準ボーンヒートと元のウェイトを、Z .98±.22の領域だけブレンドする。これで前面の股の鋭い折れを軽減した。自動ウェイトを全身へ無条件採用する処理ではない。

`bend_correctives.py` は、曲がった肘膝の接線へ連続する中心線と断面を求め、DQ変形の逆変換を使って姿勢補正シェイプキーへベイクする。補正量は関節角1〜15°で連続的に入る。各 `Bend correction ###` は該当フレームで1、前後で0。ボーンを大きく編集したら補正を再生成または再調整する。物理的な筋肉・衣服シミュレーションではない。

初期モデルにある `Bend surface correction` モディファイアは、再構築/適合時に生成される暫定物で、実測適合処理では除去して姿勢補正へ置き換える。

## 実測からの適合

- CMU/cgspeedの世界位置・回転を約120Hzから30fpsへサンプリング。挿入された最初のTポーズを除外する。
- 初期の人の向きをキャラの前方-Yへ合わせ、実測の世界回転と自作リグの中立回転を対応づける。
- キャラ自身の骨長で脚腕を再構成。脚長比で移動距離を縮小する。原速の時間を保つ。
- 足先と踵プロキシの速度から支持区間を推定。支持中は爪先/踵ピボットを固定し、実際の足裏で床Zを合わせる。旋回中の大きな足の角速度では支持を解除する。
- 遊脚は実測軌道へ接地端点のオフセットを連続補正。二骨IKで骨長を保ち、現在の骨盤の向きへ膝の前方を追従させる。
- 胴・頭の傾きを控え、大頭へ近づく腕は必要なときだけ外へ広げる。原データをそのままの体格で見せたものとは区別する。

これはキネマティックな接地であり、重心・床反力・慣性・力学的な自然さの保証ではない。モーションには元の計測ノイズもある。各動作を実際に見て判断する。

## 過去の失敗から必要な検査

- 球と棒のパーツが接しているだけの人型、正面だけ厚みがある平板化は承認形状の代わりにならなかった。一体の閉じた表面と斜め・側面の厚みで確認する。
- 自己流の周期関数で腕脚を振るだけの歩行は、人の重心移動や接地の自然さを満たさなかった。実測のタイミングを基礎に適合する。
- 股の鋭い折れ、前屈の腹の庇状の潰れ、頭と上げた腕の交差を静止・連続両方で確認する。深い前屈を短い胴へそのまま当てない。
- 足裏や画角の数値が合っても、腹の折れや腕頭交差は残った。数値だけの合格をしない。

成功した前屈にも正面・斜めのV字の強い陰影が残る。動作中の点滅・反転・急伸縮とは区別して評価する。非表示面の全干渉、指、物体の把持はこの成功例では検証していない。
