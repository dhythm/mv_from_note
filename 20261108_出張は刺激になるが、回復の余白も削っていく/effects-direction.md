# 効果の検討記録（NANKA DEKIRU）

参照：https://esoragototv.com/tools/nanka-dekiru/index.html

このファイルは採否の記録。plan.html には、採用する動きの狙いだけを書く。

## 確認した範囲（2026-11-07）

- `catalog.json` を取得した。表記の更新日は 2026-10-06。件数は 156。
- プロンプトビルダーは、ページ内の JavaScript が選んだ見本と入力欄から指示文を組み立てる。送信して結果を返すフォームではない。非公開原稿はサイトに入れていない。
- 一般化した作品説明は、手元でビルダーと同じ組み立て（作品・ねらい・選んだ見本）に使った。
  - 作品・場面：明るい紙の上のキネティックタイポグラフィ。左の柱が上がり、右の余白が同時に狭くなる。約2分。人物も地名も出さない。
  - ねらい：刺激は残したまま、回復の余白だけが先に無くなる。疲れてからでは遅い、という転換のあと、予防の一本の線が余白を少しだけ戻す。語は塊で動き、1字ずつは揺らさない。
- デモをブラウザで再生して動きを見た確認はしていない。
- 次の HTML は取得し、動きの仕組みをソースから読んだ。s16、s12、s86、g16、s15、t10。
- 見本の写真・文言・暗い背景・コードは作品に流用しない。

## 採用（仕組みだけ。見本の見た目は採らない）

| 効果 | 使うところ | 借りる仕組み | 作品用に変える点 |
|---|---|---|---|
| 数字のグラフが伸びる（s86_growing_charts） | 01〜10 の刺激の柱 | 棒の高さが、値に向かって伸びる | 王冠、順位、赤い優勝、円グラフ、折れ線、回転する数字は使わない。伸びるのは琥珀の柱だけ。暗色の見本画面は使わない |
| 歌詞が跳ねる（s16_kinetic_lyrics） | 02 の三語、03 の「体が重い。」、08 の「予防が、先。」、10 の結び | 語の塊が大きなスケールから着地する。強い語ほど入りが短い | 1字ずつに分けない。見本の歌詞と色と暗い写真は使わない。着地のあと背景を拍で拡大しない。着地後は行とカメラを動かす |
| 線が描かれていく図（s12_line_draw） | 08 の予防の線 | 線の長さを測り、stroke-dashoffset を戻して一筆で描く | 相関図にはしない。線は1本。光のにじみは付けない。描き終わってから余白の板を少し押し広げる |
| 放射状のぶれ（g16_zoom_blur） | 06 の翌日カードの入り | 中心に向かう短い放射ぶれ | 見本にある白く光る瞬間は入れない。読む間はぼかさない。中心は閉じた余白 |
| 奥行きのある横スクロール（s15_parallax_scroll） | 01 の寄り、02 と 09 の横移動 | 層ごとに移動量を変える | 章の見出しは入れない。見本の実時間の往復は使わず、フレーム時刻から層の位置を決める。暗い風景の絵は使わない |
| ピント送り（t10_focus_pull） | 06 | 奥行きのピントを、手前の柱から奥の閉じた余白へ送る | 図の層だけ。文字の層はシャープなまま。見本の写真カードと暗い背景は使わない。再生確認はしていない |

s16 の見本は、語を `scale` と `rotationX` で着地させ、強い語では背景も一瞬拡大する。語が重なる配置がある。その配置は写さない。

s12 の見本は、複数の線を順に `strokeDashoffset` で描く。今回は予防の1本だけ。

s86 の見本は、棒の伸びに加えて王冠と光の線と円グラフがある。借りるのは棒の伸びだけ。

g16 の見本は、放射ぶれと一緒に白く光る。白は採らない。

s15 の見本は、空・遠景・中景・近景に別の係数を掛けて横へ動かし、章の題を一定間隔で差し替える。借りるのは係数の差だけ。

t10 の見本は、three.js の Bokeh でピント距離を変え、カメラも揺れている。カメラの揺れは採らない。

## 不採用

| 効果 | 理由 |
|---|---|
| 一字ずつ弾んで出る字（s11_bounce_text） | 1字ずつ落ちると、読む間の字形が崩れる |
| ばねでつながる字（p23_spring_text） | 字が揺れ続ける。20261018 で読みにくいとされた動きに近い |
| 流れる帯の字（s22_marquee） | テロップ帯に見える。テロップ帯は入れない |
| 数字が回って止まる（s14_counter） | 原稿に、この動画で出す指標の数字がない。ゲージを点数にしない |
| 画面にひびが入る（g18_crack） | 余白が無くなることと、何かが割れることは原稿が分けている。白く光る瞬間もある |
| 粒子が形から形へ変わる（t01_particle_morph） | 柱と余白が溶けると、二軸が途中で別の形になる |
| 立方体が回って場面が変わる（t07_cube_flip） | 章の切り替えに見える。章表示は入れない |
| 曲の拍に合わせて切り替わる（y20_beat_cut） | 拍の頭の白い光を標準にしない。BGM は後回しで、拍位置は未確定 |
| 音の大きさで画が脈打つ（y21_audio_pulse） | 字や柱を拍ごとに拡縮すると、読みにくくなる |
| 画面分割（y35_split_screen） | 4面を拍で光らせる見本で、二軸の意味と違う |
| スピードランプ（y36_speed_ramp） | catalog の説明は「速い→ゆっくり→速い」。`src` は空で、html / mp4 / py の URL は 404。デモは未確認。06 の減速は、この見本の採用にしない |
| 残像で動きの軌跡を見せる（y27_echo_trail） | 同上、kind は video で `src` は空。柱に尾を足すと刺激以外の意味が増える。不採用 |
| パタパタ表示板（s17_split_flap） | 空港の行先に見え、1字ずつめくる |
| 字の中で動画が流れる（s18_video_in_text） | 見出しの中に映像を入れる形で、今回の文字の役と違う |

## 制作側へ渡す注意

- 採用した効果の名前は、動きの狙いを満たすための参考である。ライブラリ名だけでは合格にしない。
- Remotion で組むときは、GSAP の実時間や `requestAnimationFrame` をそのまま走らせず、フレーム時刻から位置・回転・スケール・線の進行・ピントを決める。
- デモの再生確認はしていない。上に書いた「ソースから読んだ」以外を、再生確認済みと扱わない。
