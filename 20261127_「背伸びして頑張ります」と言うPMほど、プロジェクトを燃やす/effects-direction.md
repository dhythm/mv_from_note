# 演出の適合確認

確認日：2026-11-27。[NANKA DEKIRU](https://esoragototv.com/tools/nanka-dekiru/index.html) の `catalog.json`（更新日はファイル内の 2026-10-06）を読み、採用する見本はデモのソースを開いた。非公開原稿は入れていない。見本の全ループを等速で連続視聴したとは扱わない。下の採用と不採用のうち、ソースを読んだものだけを「ソースで確認」と書く。

## 入力する一般化した説明

- 作品・場面：明るい紙色の机。予想と実際の二本の棒が伸び、隙間なく並べたブロック列が一つ遅れて倒れ、隙間のある列は遅れを受け止めて残る。
- ねらい：文字の形は崩さない。動かすのは棒、ブロック、語の塊、図のカメラ。長い棒を勝ちの印にしない。倒れる列と残る列を、同じ描き方のまま対比する。

ページが生成する章表示、固定手順、了承を得てから作り始める段は採用しない。

## JIZURA の語彙

[JIZURA](https://github.com/852wa/JIZURA) は歌詞から文字の映像を組むブラウザアプリ。利用は必須ではない。ここではアプリを動かしていない。参照したのは、このリポジトリのスキルが v0.13.0 の README からまとめた部品名だけである。非公開原稿は入れていない。NANKA DEKIRU の確認の代わりにはしていない。

- ドリーイン：03で、伸びる二本の差へ寄る言い方の参考。カメラは図の層に掛ける。数字の文字は正面のまま読む。
- ワイプ：語の塊が行のマスクから入る。1字ずつではない。
- ドリフト：読むあいだ、列や語の塊をゆっくり流す。字形の揺れにはしない。
- プッシュ：08の結びで、語の塊を寄せてから、ライムの全面へ横に振る。
- トラッキング：04で、倒れていく列に沿って図の層を送る。

採らない部品はジッター、グリッチ、爆散、拍ごとの脈動、飾りの数字。文字の形を崩すものと、意味のない飾りである。

## 制作への引き渡し

plan.html には予想と実際の棒を原稿の平均の比で伸ばすこと、隙間のない列が一つで崩れ、隙間のある列が遅れを受け止めること、結びは本人の結論で閉じることを記載した。見本のコード、画像、音は転載しない。仕組みはフレーム時刻から決まる実装へ翻訳する。最初の試作は03と04。棒の比が33.9対55.5であること、長い棒を勝ちにしないこと、バッファの列が途中で止まることを等速で確認する。
