## 実施内容と範囲（2026-11-07）

- `catalog.json` を取得し、156 件の題名・効果を読み、関係しそうな 14 件の「作り方」「プロンプト例」を読んだ。
- 5 件（p21_reaction_diffusion、p18_growth、g18_crack、t61_kintsugi、s16_kinetic_lyrics）のデモ HTML をヘッドレスのブラウザ（Chrome）で開き、仮想時間 1.5 秒・5 秒の 2 時刻の静止画を取った。**等速の再生は未確認**。p18 と p21 は 2 時刻とも育ち始めの段階で、育ちきった形は見ていない。
- プロンプトビルダーはページの表示に JavaScript が要り、この環境の取得ではビルダーの画面を操作できなかった。下の一般化した説明は手元で整理したもので、**サイトへの入力はしていない**。
- 原稿の本文や非公開の情報は外部サイトに入力していない。デモの画像・コード・音は流用しない。

## 入力（一般化した作品説明）

- 作品：手入れをやめたモノは止まらずに劣化し、いずれ負債になる、という筆者の考えを約 2 分で伝えるキネティックタイポグラフィの動画。明るい紙色の画面。
- ねらい：整った架空のアプリ画面が、時間の目盛りに合わせて、縁から伸びる雑草の線と、角から広がる錆のひびに覆われていく（早回し）。後半は、定期的に落ちるコインと青い一筆で雑草と錆が払われ、修繕跡を残したまま使える状態を保つ。

## 不採用と理由

| 効果（ID） | 理由 |
|---|---|
| 金継ぎ（t61_kintsugi） | 修繕跡を見せる仕組みは近いが、割れて飛び散る衝撃と金色の継ぎ目が加わる。金色はコイン（対価）と色の意味がぶつかり、割れる表現は「放置で徐々に劣化する」と合わない。修繕跡は s12 の線の描き方で青の細線にする |
| 燃えるように溶けて次の画へ（g08_dissolve） | 縁が燃える色が錆と紛れ、場面転換の飾りに見える |
| ピクセルが流れ落ちる（g12_pixel_sort）／画が砂になって崩れる（y109_sand_collapse） | 一気に崩れる表現は「止まらずに少しずつ劣化する」より強い急変に見える。ソフトが突然消えるような誤読を招く |
| 球が当たってタイルが崩れる（p24_tile_break） | 外からの衝撃で壊れる絵になり、放置による劣化と因果が違う |
| 数字が回って止まる（s14_counter）／パタパタ表示板（s17_split_flap） | 「カウントダウン」を数字で見せたくなるが、原稿に数値がない。数字を作らない。時間は目盛りの点で見せる |
| 奥行きのある横スクロール（s15_parallax_scroll） | 章の扉の見た目になりやすい。章表示は入れない方針。奥行きの速度差は 05 でカードが奥へ退く動きとして自前で作る |
| スピードランプ（y36_speed_ramp） | 生成映像向け。既定は作画のため不要。02 を生成映像にする判断（要判断 6）が出た場合に再検討する |
| 光漏れとフィルムの焼け（g15_light_leak） | 思い出の質感が付き、劣化の早回しが懐古に読める |

## 注意（企画側の判断として制作側に渡すこと）

- 採用した効果の狙いだけを plan.html に書いた。採否のログはこのファイルだけに置く。

- デモの動きは等速で未確認。制作側が代表区間（02→03、13→14）の試作で確かめる。
