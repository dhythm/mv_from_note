## 実行環境

- 動画AI（Dreamina／Seedance）・音楽生成・音声生成などの外部有料サービスは使用していない。クレジット消費なし
- ナレーションは追加していない（企画書どおり）
- 20261013 の制作プロジェクト（Remotion＋three.js の舞台・文字の部品・エンドロゴ・点検スクリプト）を土台に流用し、カット・素材再生・BGM はこの作品用に作り直した

## 制作内容

1. 採用動画4本をコマ単位の JPEG にし、three.js のテクスチャとしてフレーム番号から等速再生。7・8 は同じ大きさの全画面、13・15 は右寄りのパネル。追従ラベルは企画側の座標データを素材パネルと同じ親座標に変換して置いた（パネルを傾け・拡大してもラベルが外れない）
2. 7 の「制作」ラベルは座標データに無いため、素材のコマから球の出現位置を測って追従させた
3. 7→8 はカット7末尾でレビューのゲートへ寄り、カット8冒頭で同じゲートの柱へ寄った位置から引くことで接続。「以前」→「現在」の札を入れ替える。素材の再生速度は変えていない
4. レビューの拍（素材のゲートが1.5秒ごとに光る周期）に合わせ、7・8 で同じ間隔の波紋と金属音を入れた
5. 8→9 は素材の最終コマと同じ位置・大きさの末尾画像から映像窓へ縮める。15 は12秒の素材のあと、末尾画像を小窓にして結論の文字と組んだ（引き伸ばし・ループなし）
6. BGM を Python で合成（140BPM、約40か所のアクセント、11 の切れ目、15 の解放感、ロゴの終了で収める）。音楽生成サービスと比べ、映像の出来事へフレーム単位で合わせられることと費用がかからないことから選んだ
7. エンドロゴは原本 SVG の CSS アニメーションをフレーム計算へ翻訳したもの（20261013 と同一の実装）を幅1500pxで中央に配置

画面の文言は企画書のカット表に従った。絵コンテにある補助の語（「つくる量」「見る側の負担」「背景を理解する」「著者の実践」、ラベルの「指示」「テスト・VRT」「型・リンター」「規約・不要コード」「お金」「個人情報」「セキュリティ」、凡例「角丸カード＝担う人・役割 ／ 青い球＝成果物」）は絵コンテに合わせて使った。14 の「お金・個人情報・セキュリティ」「後から変えにくいデータモデル」は、文の形ではなく分岐先の札として出している。

## 確認したこと（実施した範囲）

- 静止画: 全カットの代表時刻を書き出して構図・重なり・文言を確認し、文字と素材パネル・ラベルの重なり、強調位置の誤り、6 の左右反転で文字が裏返る問題、4 の主文が表示されない不具合（画面固定層に時刻が渡っていなかった）を修正
- 代表区間: 7→8（66–76秒）と 13→14→15（154–176秒）を先に等速で書き出し、場面間を0.1秒刻みで確認してから全編へ展開。8 冒頭の接続と 13→14 の線の受け渡しをこの段階で直した
- 全編: 1秒ごとの一覧（195コマ）を目視。隣接フレームの差による動きの量を0.5秒窓で計測し、初回に静止気味と判定された 4（31–41秒）の動きを強めた。最終版で閾値未満の窓は 15.0・31.5・32.0・39.5・56.0・100.0・128.0 秒の7か所。いずれも暗い背景に文字・図形が動いている区間（カットの入り口、4 の文と領域パネルの運動）で、一覧で静止画の切替になっていないことを確認した
- エンドロゴ: `tools/check_logo.py` でパス・キーフレーム値・イージングが原本と一致（all_ok）。原本SVGを各時刻で止めた画との差は 0.1秒ごと55時刻で最大 0.05%。完成動画で 192–194 秒に完成形を保持していることを一覧で確認
- 音: 統合ラウドネス −14.1 LUFS、真のピーク −1.4 dBTP。116.98–117.22 秒は −143 dB（無音）。7 の区間は −13.7 dB、8 の区間は −10.4 dB（RMS）で密度の差がある。193.5–194.4 秒 −41 dB、194.6–195 秒 −85 dB でロゴ終了に収まる

## 未確認・注意

- **BGM と映像の相性は、私自身が音として聴いて確認できていない。** 確認したのは波形の音量・無音区間・アクセントの時刻（映像の出来事の時刻から配置）まで。冒頭・8 の見せ場・後半（13–15）を等速で再生して試聴し、曲調が合わなければ指摘してほしい
- 全編を等速で通して目視したわけではない（1秒ごとの一覧・代表区間と場面間の0.1秒刻み・動きの量の数値で確認）
- 文字の画面外検査（`node render.mjs check`）は、数字ブロックなど入れ子の座標を持つ文で誤判定するため最終判定に使っていない。外周は静止画の目視で確認した
