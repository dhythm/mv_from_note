# Blender 動画素材

## 用途

本編へ組み込む無音・文字なしの動画素材。完成動画ではない。文字、BGM、ナレーション、エンドロゴは本編の制作工程で重ねる。

| 動画 | 長さ | 使用想定 | 内容 |
|---|---:|---|---|
| `07_before.mp4` | 11秒 | カット7 | 少量の成果物が一定間隔でレビューへ届く |
| `08_backlog.mp4` | 16秒 | カット8 | 制作の投入頻度が増え、レビュー前に待機列が積もる。最後の3秒はカメラ位置を固定したレンズの引き |
| `13_quality_gates.mp4` | 16秒 | カット13 | 上流の指示、複数の検査、修正へ戻す経路を同じ空間で示す |
| `15_feedback_loop.mp4` | 12秒 | カット15の一部 | 判断が上流へ戻り、次の指示を改善する。12秒以外は本編のタイポグラフィで構成する |

納品仕様は 1920×1080 / 30fps / H.264。4本とも `../../plan.html` のカット7・8・13・15に採用済み。採用区間と文字・図形の組み合わせは同企画書を参照。`../storyboard/` の絵コンテは実際の素材フレームに文字・図形の構図を重ねたもの。本編の合成アニメーションは、制作側が代表区間で確認してから全編へ展開する。

## 表現上の前提

- 球は成果物。人員を表す記号として使わない。
- 青い球の滞留は数量の偏りであり、低品質を表さない。
- 琥珀色の球・経路は検出された問題と改善のフィードバック。
- カット7と8のレビュー周期はともに45フレーム。制作側の投入頻度が変わる。
- 個数・速度・配置は説明のための演出であり、調査結果の実測値ではない。
- 品質ゲートはすべての問題を保証する魔法の装置ではない。カット14の人による例外・重要領域の判断へ接続する。
- カット7・8は主に上側をコピーの配置候補とする。カット13・15は上流へ回り込む際に指示板が上側へ入るため、コピーの配置を場面別に変えるか、追従ラベル中心で構成する。確認画面ではカット13・15の主コピーを映像の外へ置いている。文字の動き・大きさは本編で設計する。
- 実時間の物理演算には依存せず、フレームで再現可能なキーフレームを使用。

## 再編集

`scenes/` の `.blend` は編集可能。Blender 5.2.2 LTSで作成。

`build_assets.py` をBlender MCPの `execute_blender_code` で実行して構築した。Blender MCP 1.8 / protocol 13、ローカル接続。テレメトリーは無効であることを確認。

`build_assets.py` は現在のシーンを置き換えるため、再構築には空の作業用Blenderを使う。保存済みの `.blend` を開いて編集する場合は再構築不要。

`render_assets.py` は保存シーンから静止画または連番をレンダリングする。

```sh
blender -b --factory-startup --python render_assets.py -- 08_backlog full
```

`preview/index.html` は仮の文字を重ねて実速確認するためのページ。ここにある文字は完成した本編タイポグラフィではない。

`tracks/` のJSONには、カメラに合わせて動くゲート・指示板の画面座標を収録する。左上が `(0,0)`、右下が `(1,1)`。本編で名称を重ねるときに使える。`visible: false` のフレームでは表示しない。

カット13の後合成では、指示板に「指示」、ゲートに「テスト・VRT」「型・リンター」「規約・不要コードの確認」などを対応づける。通過だけで品質が無条件に保証される説明にはせず、後続の人による判断につなぐ。

## 検証記録

2026-10-15に確認。

- 4本すべてを1920×1080・30fpsで書き出し、フレーム数（330 / 480 / 480 / 360）とデコードを検証。
- カット8は終盤6秒と投入部分2秒の代表動画で、カメラの引き・球の出現・間隔を確認してから全尺を書き出した。
- 4本をブラウザのプレイヤーで1倍速再生し、冒頭・中盤・終盤の構図、流れ、文字との重なりを確認。画面に重なる指示板があるカット13・15は、確認用の主コピーを映像外へ移した。
- 仮ラベルがカメラに追従することを確認。座標データのフレーム数も各動画と一致。
- これらは本編へ組み込む素材。完成したキネティックタイポグラフィ、BGM、ナレーションとの同期は本編の制作工程で確認する。
