# 台本（画面に出す言葉）

元記事: https://note.com/dhythm/n/n1ddb1bb63c9f

記事の筋は「問い → 原因 → 転換 → 方法 → 結論」。映像の言葉はこの順に並べる。

- **【引用】** 記事の文のまま。明朝体。`references.md` にあることをテストで確かめる。
- **【要約】** 記事の文を短くしたもの、またはつなぎの言葉。ゴシック体。記事にない主張は足さない。
- 1つの言葉のまとまりは「7文字/秒 + 1拍」以上止めて、読み切れるようにする（テストで確認）。
- 秒数の正は `video/src/lib.ts` の `BEATS`。この表はその写し。

## BGM

`video/bgm/compose.ts` でこの映像のために合成した曲（外部音源なし、権利の制約なし）。84BPM。

- 問い：明るい分散和音。カードが飛び出すたびに高い粒。「少ない」で音が抜け、「なぜ」で宙に浮いた和音
- 原因：小さなリズムが入り、短調寄りの進行
- 崩落前：同じ音の刻みと上昇音で張りつめ、崩れる瞬間に低い一撃。そのあと一度静かになる
- 転換・方法：あたたかい長調で立て直す。語の入れ替えに合わせて高い2音が入れ替わる
- 結論：「作り上げる」の1文字ごとに音階を一段ずつ積み、C の和音に着地してフェードアウト
