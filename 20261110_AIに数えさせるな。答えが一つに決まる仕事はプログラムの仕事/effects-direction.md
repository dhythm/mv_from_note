## 採用する仕組み

動きの軸は三つ。光が薄まる。一枚ずつ送る。歯車と吹き出しに分ける。これは出発点の演出案であり、効果の数や組み合わせの上限ではない。記事の意味、字形、可読性、大きな画面運動を守り、より伝わる動きへ発展させてよい。

| 候補 | 使うところ | 採る仕組み | 見本から採らないもの |
|---|---|---|---|
| s16 歌詞が跳ねる | 01 の「問題ありません」、03 の「渡し方？」、06 の「一つずつ。」、09 と 13 の決め語 | 語の塊が着地する。意味の決め語を、字の形を保ったまま大きく出す | 1 字ずつの跳ね、語の重なり、可読性を失う回転、暗い高架 |
| s15 奥行きのある横スクロール | カードの列を次のカットへ渡すとき、06 の中央と脇の列 | 近くのカードは大きく動き、文字の層は別の速さにする | 暗い背景、章題、山と矢印 |
| s23 弾んで出る吹き出し | 01、08、09、10 の吹き出し | しっぽの先から形が出て、中の語は塊で入る | 1 字ずつ出すこと、人物の写真、部屋の背景 |

## 採用しないもの

| 候補 | 理由 |
|---|---|
| t10 ピント送り | ぼかしは、見ていないカードを「読めない」にする。この作品の見落としは、灰色の穴であって、ピントの外れではない。デモは暗いギャラリーだった |
| t16 光の筋 | 逆光と暗い影が前提になる。紙色の上の薄い輪とは別の光 |
| g16 放射状のぶれ | catalog は 0.1 秒の白を含む。このフレームでは白は見えず、全ループは未確認。白フラッシュは入れない |
| s12 線が描かれていく図 | このフレームでは図が完成していなかった。手順図は、ファイルの見落としの絵にならない |
| y35 画面分割 | 09 は左右の仕分けであり、4 本を拍で光らせる見本ではない。デモは未確認 |
| s14 数字が回って止まる | 「20」は絵の枚数であり、発表する測定値ではない |
| s11 一字ずつ弾む字、p23 ばねでつながる字 | 字の形を常に揺らす。読む間は行とカードとカメラを動かす |
| t89 3D 空間で動く字幕 | 文字を 3D のテクスチャにすると、タイポグラフィが字幕になる |
| s18 字の中で動画が流れる | 未承認の動画を字の中に入れない |
| s17 パタパタ表示板、s20 回る立方体の字 | 行き先や選択の意味になる。仕分けは歯車と吹き出しで足りる |
| g07 波のように画がゆがむ | カードがゆがむと、ファイルの形が崩れる |
| t06 光のにじみ、t01 粒子 | 光を足すと「薄まる」がぼやけ、粒子は意味のない飾りになる |

plan.html には、採用する動きの狙いだけを書く。実装はフレーム時刻から決まる形へ翻訳する。デモを見たことを、本編の完成確認とは扱わない。
